02 · Rental / Return

셀프 대여반납무인 대여 시스템

회원 등급에 맞춰 자동으로 대여, 반납, 연체 관리가 됩니다.
결제 완료까지 사람의 손이 필요 없고, 결과는 문자로 즉시 안내됩니다.

대여 회원이 아닌 손님도 요금 정책에 따라 단건 대여료가 자동 계산되어 이용할 수 있어요.
약정 등급을 초과하는 제품을 대여할 경우 초과 요금이 자동으로 부과됩니다.
반납 시점에 연체 일수만큼 연체료가 자동 합산되어 추가 결제가 진행됩니다.
03 · Signup / Recharge

셀프 가입 · 충전고객이 직접 처리

전용 단말기에서 회원 가입과 요금 충전을 손님이 직접 처리합니다.
카운터에서 정보를 받아 적느라 시간을 쓸 필요가 없어요.

아이 이름과 보호자 연락처만으로 회원 가입이 끝납니다. 불필요한 입력은 모두 제거했어요.
점주님이 설정한 요금제 정보가 자동으로 단말기에 반영되어 손님이 직관적으로 고를 수 있어요.
충전 완료 시 결제 내역과 가입 요금제 정보가 자동으로 안내되고 문자로도 발송됩니다.

04 · One-Click Registration

제품 일괄 등록1,000건도 한 번에

제품번호만 붙여넣으면 시스템이 자동으로 정보를 조회해 등록과 입고까지 처리합니다.
신상품을 받은 다음 매장 운영 준비 시간이 분 단위로 줄어듭니다.

한 번에 최대 1,000개까지 등록할 수 있어 신상품 입고 작업이 클릭 한 번으로 끝납니다.
매일 새벽 갱신되는 제품 데이터베이스를 통해 정보가 항상 최신 상태로 유지됩니다.
DB에 없는 신상품은 본사로 자동 등록 요청이 들어가 다음 동기화 때 정상 반영됩니다.
