# 데모몰(DEMOMALL) 관리자 — 페이지별 기능 명세

> 대상: `https://demo3.mallup.co.kr/admin/`
> 각 페이지의 핵심 기능 / 입력항목 / 검색필터 / 액션을 요약. (실 데이터 인증세션 기반 추출)
> 표기: **검색필터** = 목록 상단 조회조건, **컬럼** = 목록 테이블 헤더, **액션** = 주요 버튼

---

## 1. 환경설정

### 1.1 상점환경설정 `setup/config_manager.asp`
상점·사업자 기본정보 통합 설정 폼. 입력: 상점관리자 아이디/비밀번호/관리자명, 상점관리자·부관리자 핸드폰번호, 관리자 메일(내부/외부 메일서버 주소·포트·계정), 상점명, 대표자명, 개인정보관리자, 입점업체 담당자, 회사명·주소·대표전화·Fax, 사업자등록번호, 통신판매업신고번호, 업태/종목, 운영시간. **액션**: 확인(저장).

### 1.2 사이트환경설정 `setup/config_site.asp`
사이트 전역 운영정책 설정(대형 폼, 토글 53종). 주요 항목: 브라우저 Title·검색엔진 키워드·메타태그·오픈그래프(SNS), 법인인감도장, 메인페이지 로딩(캐시 갱신주기), 로그인타입, 인트로 설정, 가입 인증번호, B2B 기능, SSL 사용유무, 소스공개여부, 업로드 컴포넌트, 모바일/태블릿/APP 사용유무, 카테고리 메인설정, PC 리스트 열 갯수, 리스트·상세 이미지 사이즈, 워터마크(위치·크기), 카카오톡 공유, 품절상품 진열, APP 할인, 관리자 구매확정 기간, CODEF 은행연동. **액션**: 확인, 선택삭제.

### 1.3 도메인관리 `setup/domain_info.asp`
분양몰별 도메인 목록 관리. **컬럼**: 번호·분양몰·도메인·기본도메인·관리메뉴. 도메인 추가 입력 + 기본도메인 지정(라디오).

### 1.4 SNS설정 `setup/sns_config.asp`
간편 로그인/SNS 연동 키 관리. 네이버·페이스북·카카오·구글·애플 간편가입(App ID/Key), 네이버톡톡·카카오채널·카카오톡 공유 코드, 페이스북·인스타그램 연동(Client ID/Secret, sessionid). 사용유무 체크 7종. **액션**: 메뉴얼 보기, 확인.

### 1.5 입점사 승인환경설정 `setup/config_dealer.asp`
입점사(Mall-in-Mall) 운영정책. 입점사 가입 승인여부, 상품당 수수료 설정, 상품 등록/미진열 승인여부, 정산관리(정산주기 select: 일/주/15일/월정산). **액션**: 확인.

### 1.6 어휘설정 `setup/config_vocab.asp`
공통 코드/어휘 관리. 분류 select: 전화 지역번호·휴대폰 인식번호·이메일 도메인·은행·배송 요청사항·1:1 친절상담. **컬럼**: 어휘 분류·항목 설정.

### 1.7 배송설정 `setup/config_delivery.asp`
배송정책 + 택배사 연동. 기본/네이버페이 배송료·무료배송 한도·배송방식(라디오), 택배사명/연락처/URL/스윗트래커 코드, 스마트택배 사용. 체크 18종. **컬럼**: 사용여부·배송회사명·연락처·URL·스윗트래커CODE.

### 1.8 적립금 설정 `setup/config_cmoney.asp`
적립금(포인트) 정책. 적립금 명칭, 회원가입/회원초대 적립, 최소·최대 사용액, 적립률·사용제한 비율, 수신동의·상품평·이미지리뷰·게시글·출석체크 적립, 적립금 소멸설정, 적립금 선할인. 라디오 7종.

### 1.9 예치금 충전 설정 `setup/config_cash.asp`
예치금(데모머니) 충전 구간 설정. **컬럼**: NO·충전금액·추가 충전금액·삭제. 충전금액/추가금액 행 추가.

### 1.10 상점운영정책 `setup/textManager.asp`
약관/운영정책 문구 관리. **컬럼**: No·제목·적용위치·링크URL(PC/모바일)·관리. 정책 문서 등록/노출위치 지정.

### 1.11 결제정보설정 `setup/config_pay.asp`
PG/결제수단 통합 설정(대형 폼). 결제대행사 select(웰컴페이·KSNET·나이스페이·이니시스·KCP·K1PS·이노페이·코밴·토스페이먼츠·페이맵 등), 결제수수료(카드/계좌/가상계좌/에스크로/휴대폰, 단위 %·원), 수수료 부담주체, 할부 개월·무이자할부 기간, 페이레터 휴대폰결제, 제로페이, 간편결제, 에스크로 상점ID/signKey 등. 체크 18종.

### 1.12 온라인입금계좌 `setup/config_pay_online.asp`
무통장 입금계좌 관리. **컬럼**: NO·은행명·계좌번호·예금주·주계좌·삭제. 주계좌 지정(라디오).

### 1.13 로그인/로그아웃 로그 `setup/admin_LoginList.asp`
관리자 접속 로그 조회. **검색필터**: 관리자유형(전체/본사/입점사), 검색키(접속IP/접속ID)+검색어. **컬럼**: No·분류·접속ID·구분·접속IP·날짜/시간.

### 1.14 로그인 2차인증 관리 `setup/admin_LoginSecurity.asp`
관리자 2차인증 등록 목록. **컬럼**: 선택·이름·인증수단·등록일자·등록자IP.

### 1.15 로그인 접근IP관리 `setup/admin_LoginAuthority.asp`
관리자 접근 허용 IP 화이트리스트. **컬럼**: 선택·이름·IP·등록일자·등록자IP.

### 1.16 페이지 접속로그 `setup/admin_moveList.asp`
관리자 페이지 접근 감사로그. **검색필터**: 전체/아이디/url/IP/등록일자 + 검색어. **컬럼**: 선택·아이디·URL·로그인타입·IP·등록일자. 선택 삭제용 체크박스.

### 1.17 개인정보 조회/수정 로그 `setup/admin_movementList.asp`
개인정보 접근 이력(법적 의무 로그). **검색필터**: 전체/아이디/url/제목/메모/IP/등록일자 + 검색어. **컬럼**: 선택·아이디·URL·제목·메모·로그인타입·IP·등록일자.

## 2. 디자인관리

> **공통 디자인 모듈**: 메인/서브메인/인트로/상단/하단 페이지는 모두 동일한 **"영역(Area) + 스타일(Style)" 위젯 빌더** 구조. 각 영역마다 스타일선택·영역명·정렬·노출상태·순서·HTML편집·설정을 제공하고 **[영역추가]**로 위젯을 쌓는다. 스타일 풀: (PC) 탑탑메뉴·로고&검색·메인탑메뉴·오른쪽날개·메인배너·탑탑배너·스크롤탑메뉴 / (Mobile) 푸터·상단영역·좌측메뉴·상단GNB·비쥬얼텍스트·타임세일·카테배너.

### 2.1 디자인환경설정 `design/siteDesign.asp`
사이트 전역 디자인 변수. 사이트 정렬(라디오), 배경색, 테마색상1~3, 가격 스타일(색상·크기), 사이트 넓이 설정.

### 2.2 로고관리 `design/topDesign.asp`
로고/파비콘 등 상단 이미지 업로드 관리.

### 2.3 기타이미지 `design/icon_image.asp`
사이트 공통 아이콘/기타 이미지 업로드 세트 관리(아이콘 영역 다수).

### 2.4 PC 스타일관리 `design/main_style.asp`
PC 위젯 스타일(스킨) 라이브러리. **컬럼**: No·스타일명·샘플이미지·상품/배너포함여부·롤링여부·사용영역·관리. (108행 — 스타일 다수 보유)

### 2.5 PC 메인페이지관리 `design/main.asp`
PC 메인페이지 위젯 빌더(핵심·대형 화면). 영역별 스타일 배치, 상품 진열수(goodsAmt) 지정, HTML 직접편집 토글, 노출/순서 제어. **컬럼**: 스타일선택·영역명·정렬·신규등록·위치보기·노출상태·순서·HTML편집·설정.

### 2.6 PC 서브메인페이지관리 `design/sub_main.asp`
카테고리(catecode)별 서브메인 페이지 빌더. 페이지명 + 카테고리 선택 후 영역/스타일 구성. **[영역추가]**.

### 2.7 PC 인트로페이지관리 `design/sub_intro.asp`
인트로(랜딩) 페이지 위젯 빌더. 메인과 동일한 영역/스타일 구조.

### 2.8 PC 서브상단부분관리 `design/top.asp`
서브 페이지 공통 상단(헤더) 영역 빌더.

### 2.9 PC 서브하단부분관리 `design/bottom.asp`
서브 페이지 공통 하단(푸터) 영역 빌더.

### 2.10 왼쪽메뉴관리 `design/leftmenuManager.asp`
좌측 메뉴 위젯 빌더. 사용위치(gubun: 고객센터/마이페이지/기타) 선택 후 영역/스타일 배치. **컬럼**: 스타일선택·영역명·사용영역·노출상태·설정.

### 2.11 PC 페이지관리 `design/pagemaker.asp`
커스텀 단독 페이지 생성기(CMS). **컬럼**: No·제목·링크경로&미리보기·왼쪽메뉴·등록일·관리.

### 2.12 모바일 디자인설정 `mobile/design/*`
PC와 동일한 빌더 구조의 **모바일 전용** 세트:
- **스타일관리** `main_style.asp` (98행), **메인페이지관리** `main.asp`(대형), **서브메인** `sub_main.asp`, **인트로** `sub_intro.asp`, **서브상단** `top.asp`, **서브하단** `bottom.asp`, **아이콘이미지** `icon_image.asp`, **페이지관리** `pagemaker.asp`. 스타일 풀이 모바일 전용(푸터/타임세일/카테배너 등)으로 구성.

### 2.13 이벤트관리 `design/custom_event.asp`
프로모션 이벤트 페이지 관리. **검색필터**: 제목/내용. **컬럼**: No·이미지·제목·링크경로&미리보기·진행상태·등록일·조회수·관리.

### 2.14 기획전 관리 `design/eventmall_list.asp?method=100|200|400`
기획전 목록(일반/분류/할인 = method 파라미터로 구분). **검색필터**: 기획전제목·번호, 상품(코드/번호/명), 카테고리, 진행/대기/마감, 등록일. **컬럼**: No·제목·입점업체·링크경로&미리보기·왼쪽메뉴·진행상태·관리.

### 2.15 오늘만이가격 관리 `design/eventToday_list.asp?method=700`
한정 특가(타임딜성) 기획전 관리. **검색필터**: 제목·번호, 마감/진행, 등록일. **컬럼**: No·제목·입점업체·기간·링크경로&미리보기·진행상태·관리.

### 2.16 기획전등록 `design/eventmall_reg.asp`
기획전 신규/편집 폼(매우 상세). 기획전구분, 제목, 내용(PC/Mobile 에디터), 행사기간(시작·종료 시각 select), 진열수, 재고수량 노출, 왼쪽메뉴 연결, 이미지사이즈, 카테고리, 메인노출, 상단 타이틀 진열타입, 동영상 소스, 세트상품/할인율/관련추천상품 구성. **액션**: 상품선택, 엑셀샘플다운·엑셀업로드, 올리기/내리기, 쿠폰선택, 일괄적용, 오늘만이가격저장, 등록하기, 선택삭제.

### 2.17 기획전 환경설정 `design/config_event.asp`
기획전 공통 표시정책(PC/Mobile select). 상단 배너, 리스트 열 수, 이미지사이즈, 노출옵션, 분류노출, 종료/마감임박 아이콘, 마감일(DeadlineDay) 설정.

### 2.18 메일폼관리 `design/mailform.asp`
자동발송 메일 템플릿 편집. 폼 종류(select): 기본/회원가입축하/승인대기/주문완료/입금확인/배송시작/입점업체가입/승인 등. 제목·본문(에디터) 편집.

### 2.19 팝업관리 `design/popup.asp`
사이트 팝업(레이어/윈도우) 관리. **컬럼**: 번호·제목·구분·기간·입력방법·실행·진행·사이즈및위치·색상·관리·팝업보기.

## 3. 상품관리

### 3.1 카테고리관리 `goods/new_category.asp`
1~3차 분류 트리 카테고리 관리(드래그/체크 기반, 69행 트리). 카테고리 추가·수정·노출 설정.

### 3.2 상품목록 `goods/goods_list.asp` ★핵심
전체 상품 그리드 + 강력한 검색/일괄처리 허브.

### 4.1 주문 목록(전체/상태별) `order/order_list.asp?menu=...` ★핵심

- **검색필터**: 검색대상(주문번호/주문자ID·명·이메일·연락처/수령인명·전화/입금자명), 기간기준(주문일/결제일/배송중/배송완료/구매확정), 1~3차 카테고리, 상품(코드/명), 상품종류·결제수단·결제환경(PC/모바일)·정산여부 라디오.
- **목록옵션**: 줄수(10~500), 정렬(주문일/번호/금액/주문자/수령인).
- **액션**: 상태 일괄변경(chgState: 입금확인중/결제확인/상품준비중/배송중/배송완료), 엑셀양식별 다운로드, 배송업체 지정(한진/롯데/CJ/로젠/우체국/직접/경동) 송장 입력, 네이버페이 취소사유 처리. 행별 체크박스 일괄처리.
- **컬럼**: NO·주문번호·주문일시·총주문금액·배송비·주문자·결제상태·진행상태.

### 7.3 성별 매출 `statistics/sale_data_sex.asp`
