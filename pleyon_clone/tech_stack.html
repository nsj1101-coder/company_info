BullMQ Redis Cron

알림톡 발송 · AI 주간 리포트 · 일일 정산 · 연체 알림. 사용자 응답에 영향 없음.

결정 기준 (How to Choose)
  • 옵션 A (단일 풀스택) · 3개월 일정, 2,000만 견적, 가맹 ~30개 매장 규모일 때 → 권장
  • 옵션 B (백엔드 분리) · 가맹 50개+ 확장 계획 명확, 외부 시스템(ERP·세무) 다수 통합 예정일 때
  • 2차 단위 진입 시점 · 1차 단위를 옵션 A로 시작 → 트래픽 폭증 시 백엔드 분리(옵션 B)로 자연스럽게 마이그레이션 가능
권고 옵션 A · Next.js 16 + React Native(Expo) 단일 풀스택 기본 채택 — 3개월·2,000만 일정에서 웹·앱 코드 공유로 인력 1팀 운영이 가능하며, 가맹 30개 매장까지는 인프라 비용 부담이 가장 낮습니다.
