블럭팡 남정일 담당자님 안녕하세요, MaxImpact입니다.

블럭팡의 가맹 운영 통합 시스템 구축 의뢰 잘 받았습니다. 업계 1위 레고대여점 브랜드답게 운영 디테일 요구사항이 단단하셔서, 플레이온 운영 프로그램을 벤치마킹 분석한 뒤 12주·2,000만원(VAT 별도) 안에서 블럭팡 가맹점이 안정적으로 돌아갈 수 있는 구성으로 정리해 첨부 드립니다.


[1. 핵심 제안 요지]

1차 단위 (코어) ₩ 20,000,000 (VAT 별도) / 12주 / 3개월 무상 유지보수 조건으로 제안 드립니다. **본 금액은 최종 견적이 아니며, 미팅 후 요구사항 확정에 따라 항목·범위·금액 모두 조정 가능합니다.** 플레이온 11년 누적 기능 중 점주가 매일 쓰는 핵심 40%를 안정적으로 구현하고, 부가 영역은 2차 단위로 순차 개발하는 단위별 순차 출시 전략입니다.

저희가 의도적으로 한 가지 안 한 게 있습니다 — POS·키오스크·자체 단말기는 제외하고, 점주가 태블릿 한 대로 카운터를 운영하는 모델로 통합했습니다. 1인 운영의 80% 동작을 왼손 엄지로 가능하도록 설계합니다.


[2. 1차 단위 통합 범위 (12주 / ₩ 20M)]

- 본사·점주·직원·손님 4단 권한 시스템 (멀티테넌트 PostgreSQL)
- 입퇴실 · 홀드 · 상품판매 연동
- 대여반납 · 1회/중복 대여 · 자동 연체료 계산
- 요금제 3종 (시간당·정액·횟수) + 등급별 초과요금 + 포인트
- 토스페이먼츠 PG 결제 (요금충전·상품·연체료·환불)
- 카카오 알림톡 5종 (가입·충전·입실·퇴실·대여) + SMS fallback
- Claude / GPT API 기반 AI 매장 인사이트 5항목 (주간 자동 리포트)
- 채널톡 SDK 임베드 (본사 ↔ 점주 즉시 채팅)
- 본사 멀티테넌트 대시보드 + 점주 단일매장 어드민
- Next.js 16 웹 (PC + 태블릿 브라우저)
- React Native + Expo 태블릿 전용 앱 (iPad + Android)


[3. 2차 단위 (1차 오픈 후 협의해 순차 개발)]

- 요금제 추가 3종 (월정액·선불·포인트 전용)
- 외부 레고 DB 자동 동기화 (매일 새벽 1,000건 일괄 입고)
- AI 매장 분석 21항목 풀세트 + 일간 리포트
- 매장용품 쇼핑몰 (과자·음료·소모품)
- 그룹회원 (형제·자매 묶음 요금제 공유)
- 운영 메모 · 챗봇 도움말 · 매장 캘린더 등 부가 기능

→ 1차 단위 오픈 후 실데이터를 보고 어떤 항목을 먼저 확장할지 안전하게 결정하는 게 핵심입니다.


[4. 차별점 - "기능 수"가 아니라 "점주의 시간"]

플레이온은 11년·18만 줄·88 테이블 누적이지만, 점주가 하루 종일 쓰는 기능은 사실 40% 안쪽입니다. 무리하게 풀세트를 12주에 욱여넣는 대신, 가장 자주 쓰는 흐름을 가장 안정적으로 만드는 것이 우리의 접근입니다.

특히 두 가지에 가장 많은 시간을 할애했습니다:

(1) 요금 규칙 엔진 — 시간당·정액·횟수의 3종 요금제, 등급별 초과요금, 일수 단위 연체료를 엔진이 알아서 계산. 점주는 결과만 확인.
(2) 웹 + 태블릿 앱 코드 공유 — 모노레포로 묶고 도메인 패키지를 공유. 같은 인력이 두 플랫폼을 동시에 안정적으로 끌고 갈 수 있는 구조.


[5. 기술 스택]

옵션 A (권장): Next.js 16 + React 19 + Tailwind 4 + Prisma 7 + PostgreSQL 16 + React Native 0.76 + Expo SDK 53 (단일 풀스택 모노레포)
옵션 B: 위 프론트는 동일, 백엔드만 NestJS 11로 분리 (트래픽 큰 확장 대비)

두 안 모두 같은 견적·같은 일정으로 가능하며, 가맹 20개 매장까지는 옵션 A 권장. 외부 SaaS 연동은 동일 — 토스페이먼츠 / NHN Cloud 알림톡 / 채널톡 SDK / Anthropic & OpenAI SDK. 항목별 비교, 6계층 아키텍처, 월간 운영비용 추정까지 첨부 기술표 4p에 정리했습니다.
