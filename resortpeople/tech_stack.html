데이터 흐름과 권한 분리.

9개 지점이 같은 코드베이스와 같은 DB를 공유하지만, 권한 매트릭스로 각자 자기 데이터만 보게 분리됩니다. 데이터 흐름은 사용자 → 페이지 → API → DB → 알림으로 단일 방향입니다.

LAYER 01 · CLIENT

모바일 사용자 · 9개 지점 페이지

지점별 고정 URL (예: resortpeople.com/r/mapo). 모바일 우선 반응형. PWA 캐시로 재방문 속도 최적.

Next.js 16React 19Tailwind 4PWA
LAYER 02 · ADMIN

본사·지점 어드민 — 같은 코드, 다른 권한

본사 로그인은 전체 9개 지점 콘텐츠 편집·통계 조회. 지점 로그인은 자기 지점 리드만. NextAuth로 역할 기반 라우팅.

NextAuth 5역할 미들웨어인라인 편집기 (Tiptap)
LAYER 03 · API

Next.js Route Handlers — 풀스택 통합

웹과 어드민이 같은 API를 사용. 리드 등록, 할인 코드 발급, 콘텐츠 갱신, 통계 조회 모두 단일 API. 권한 미들웨어로 자동 검증.

Route HandlersTypeScriptZod 스키마 검증Prisma Client
LAYER 04 · DATA

PostgreSQL — 멀티테넌트 row-level 분리

모든 테이블에 branch_id 컬럼. 쿼리마다 사용자 역할 기반 필터 자동 적용. 본사는 branch_id 무조건, 지점은 자기 ID만.

PostgreSQL 16Prisma 7RLS (선택)마이그레이션 관리
LAYER 05 · NOTIFY

알림톡 · SMS · 이메일

리드 등록 → 본사·지점 알림 + 고객에게 할인 코드 알림톡. 미수신 시 SMS 자동 대체. 본사가 월초 단체 발송 가능.

NHN Cloud 알림톡SMS FallbackBull Queue

KEY DECISIONS
04 / 05

기술 선택 근거와 대안.

각 기술이 왜 이 선택이며 어떤 대안이 가능한지, 향후 확장 시 어떤 변경이 가능한지를 정리합니다.

결정 영역
선택 · 우리가 권장
대안 · 향후 검토
웹 프레임워크
Next.js 16 App Router — 정적 사전 빌드 + 어드민 갱신 시 ISR로 자동 재생성. 9개 지점에서 SEO가 안정적으로 동작.
Astro 또는 Remix — 더 가벼운 옵션이나 9개 지점 어드민 통합 시 NextAuth 같은 생태계 부재.
데이터 분리 방식
Single DB · 멀티테넌트 컬럼 — branch_id 컬럼 하나로 분리. 본사 통합 통계와 지점 격리를 동시에 보장. 운영 비용 가장 낮음.
지점별 DB 분리 — 강한 격리지만 9개 DB 운영 비용·통합 통계 작성 어려움.
어드민 인터페이스
인라인 편집기 (Tiptap) — 페이지 위에서 바로 편집·미리보기. 본사가 의뢰 없이 매월 콘텐츠 갱신 가능.
CMS 분리 (Strapi, Sanity) — 더 강력하나 학습 곡선이 가파르고 본사 직접 운영에 부담.
알림 발송
NHN Cloud 알림톡 — 카카오 비즈니스 채널 인증 후 5종 템플릿 발송. 도착률 SMS보다 높음.
자체 SMS 발송 — 알림톡 미승인 시 fallback. 비용은 알림톡 대비 3배.
호스팅
Vercel · 인천 리전 — Git push 자동 배포, 9개 지점 동시 트래픽 자동 스케일. 모바일 첫 로드 1초 이내.
AWS ECS · 자체 운영 — 더 강력한 제어이나 운영 비용 증가, DevOps 인력 필요.
이미지 관리
S3 + Vercel Image — 자동 WebP 변환 + 사이즈 압축. 본사가 원본만 올리면 자동 최적화.
자체 CDN 운영 — 비용 발생, 자동 최적화 미지원.
결제 (PG)
1차 단위에서는 포함하지 않음 — 리드 캡처 + 할인 코드만 운영. 매장 결제는 기존 POS 그대로.
2차 단위에서 토스페이먼츠 또는 KCP 연동 — 별도 견적, 약 400만 원 예상.
확장성
10번째 지점부터 콘텐츠 등록만으로 추가 — 1지점 셋업 30분 이내. 50만 원 / 지점.
지역별 분기 (예: 일본·중국 확장) — 다국어 처리 추가 시 별도 견적.

OPERATIONS & SECURITY
05 / 05

운영·보안·확장.

정식 오픈 이후 운영 단계에서 발주처가 안심할 수 있도록, 보안·백업·확장 정책을 명확히 정리합니다.

OPERATIONS

일상 운영

  • 본사가 매월 콘텐츠 직접 갱신
  • 지점장이 자기 지점 리드 응대
  • 모니터링 자동화 (Sentry 알림)
  • 월간 통계 리포트 자동 생성
  • 오픈 후 2개월 무상 핫픽스
SECURITY

보안 정책

  • HTTPS 강제 (Let's Encrypt 자동 갱신)
  • 본사·지점 권한 미들웨어 자동 검증
  • 비밀번호 bcrypt 해시 저장
  • 리드 개인정보 암호화 저장
  • 관리자 접근 IP 화이트리스트 옵션
  • 주 1회 DB 자동 백업 (AWS RDS 스냅샷)
SCALE

확장 시 대응

  • 10번째 지점부터 콘텐츠 등록만
  • 1지점 추가 셋업 30분 · 50만 원
  • 트래픽 증가 시 Vercel 자동 스케일
  • DB 부하 시 RDS 인스턴스 업그레이드
  • 2차 단위 결제 연동 별도 협의
  • 다국어 확장 시 i18n 구조 추가

운영 인수인계 — 발주처가 직접 할 수 있는 일.

매월 갱신

본사 콘텐츠 운영

  • 시간표 변경
  • 이벤트 등록·만료
  • 강사 카드 추가·교체
  • 지점별 사진 갤러리 교체
  • 알림톡 문구 수정
일상 응대

지점 리드 관리

  • 자기 지점 신규 리드 조회
  • 응대 상태 변경
  • 응대 메모 작성
  • 리드 CSV 추출
  • 월간 응대 통계 조회
의뢰 영역

우리가 처리

  • 신규 컴포넌트 추가
  • 인터랙션·애니메이션 변경
  • 지점 추가 셋업
  • 결제 시스템 연동 (2차)
  • 장애·심각 버그 대응
