WORK BREAKDOWN STRUCTURE

6주 · 30일 · 9개 지점 동시 오픈

9개 지점을 한 코드베이스로 묶고, 본사 한 명이 매월 콘텐츠를 갱신할 수 있는 운영 어드민까지 6주에 안정 오픈합니다.

본 문서는 일정·작업 단위·투입 시간·담당 롤·산출물을 분해한 WBS이며, 견적서 별첨 자료로 제출됩니다.

4단계 · 각 단계의 코어 산출물

6주를 4단계로 나눕니다. 각 단계는 독립적으로 평가 가능한 산출물을 갖고, 단계 종료 시 발주처 확인 후 다음 단계로 진행합니다.

PHASE 1 · W1

DESIGN

브랜드 시스템 확정. 와이어프레임. 멀티테넌트 DB 스키마. 9개 지점 데이터 모델.
PHASE 2 · W2

BUILD CORE

공통 컴포넌트 라이브러리. 첫 지점 페이지. 멀티테넌트 라우팅. 콘텐츠 입력 폼.
PHASE 3 · W3–W5

EXPAND + ADMIN

나머지 8개 지점 일괄 발급. 리드 캡처 + 5% 코드. 본사·지점 어드민. SMS 발송.
PHASE 4 · W6

LAUNCH

9개 지점 동시 QA. 운영자 온보딩. 인수인계 문서. 정식 오픈.

투입 인력과 주요 리스크.

3명이 동시 투입되어 6주 안에 9개 지점을 안정 오픈합니다. 주요 리스크는 사전 인지하여 협의 경로를 마련해 둡니다.

TEAM (6주 동시 투입)

ROLE 01 · PM

PM 겸 백엔드

  • 요구사항·일정 총괄
  • DB 설계·권한 매트릭스
  • 발주처 단일 창구
  • SMS 발송·콘텐츠 입력 지원
  • 약 100시간 (전체)
ROLE 02 · 풀스택

풀스택 (메인)

  • 9개 지점 페이지·반응형
  • 리드 엔진·할인 코드
  • 본사·지점 어드민 핵심
  • 인라인 편집기
  • 약 220시간 (W2–W6)
ROLE 03 · 디자인·QA

디자이너 · QA

  • 브랜드 시스템·와이어 (W1)
  • 9개 지점 동시 QA (W6)
  • 운영 매뉴얼 시각화
  • 약 80시간 (전반·후반)

MAJOR RISKS

리스크
레벨
대응
9개 지점 콘텐츠 (사진·문구) 발주처 측 수집 지연
HIGH
W1 종료 전 콘텐츠 수집 체크리스트 전달. W3까지 미수령 시 본사 표준 콘텐츠로 임시 발급 후 차후 교체.
월간 시간표 데이터 양식이 지점별로 다름
MID
W2에 표준 시간표 양식 확정. 기존 양식은 일괄 변환 스크립트로 처리.
9개 지점 동시 QA 시 회귀 이슈 발생
MID
샘플 지점 1곳을 W2에 완성해 패턴 검증 후 W3에 확장. W6에 회귀 QA 집중.
카카오 알림톡 옵션 추가 요청 발생
MID
1차 단위는 SMS·이메일 기반. 알림톡 옵션은 별도 단가 (150만 원). 카카오 비즈니스 채널 인증 5~7 영업일 소요.
결제 (PG) 연동 요청 추가 발생
LOW
1차 단위 범위 외임을 명시. 2차 단위 별도 견적 협의. 1차 코드 베이스에서 확장 가능 구조 유지.
10번째 지점 이후 추가 요청 발생
LOW
콘텐츠 등록만으로 즉시 가능 (40만 원 / 지점). 셋업 시간 30분 이내.
