§ 01 The Strategy

"지점마다 따로 만들기"는 3개월 뒤 무너집니다.

9개 지점을 각각 따로 제작하면 다음 시즌 시간표 갱신 한 번에 9번의 작업이 들어가고, 본사가 운영을 놓는 순간 페이지는 죽습니다. 리조트피플은 브랜드 공통 컴포넌트는 한 번 만들고, 지점은 데이터만 다르게 운영하는 멀티테넌트 구조로 가야 매월 콘텐츠 교체가 한 시간 안에 끝납니다.

본 제안은 1차 단위에 9개 지점 + 본사 어드민 + 리드 처리 + 알림톡까지 한 번의 계약으로 묶고, 향후 지점 확장은 콘텐츠 등록만으로 가능한 구조로 설계합니다.

UNIT 1 — 1차 단위

코어 시스템 + 9개 지점

6주 / ₩ 7M

  • 리드 캡처 + 5% 할인 코드
  • 지점 어드민 (리드 조회 전용)
  • SMS · 이메일 알림 기본

  • 카카오 알림톡 5종 (+150만 원)

§ 02 The Users

사용자는 4명, 화면은 4종.

§ 05 The Lead Flow

문의는 리드로, 리드는 할인 코드로.

페이지 안에서 문의를 남기면 본사·지점 양쪽으로 즉시 알림이 가고, 고객에게는 5% 추가 할인 코드가 알림톡으로 자동 발송됩니다. 등록 → 코드 발급 → 매장 결제 시 사용 → 전환 추적까지 한 흐름으로 묶입니다.

01
리드 등록

모바일 페이지 안에서 이름·연락처·관심 프로그램 입력

02
할인 코드 발급

등록 즉시 5% 코드 생성 + 알림톡 자동 발송

03
지점 알림

지점 어드민에 신규 리드 푸시 + 응대 대기 표시

04
응대 처리

지점장이 응대 상태와 메모 입력

05
전환 추적

코드 사용 시 매출과 매칭 → 본사 리포트

— THE INSIGHT
"지류 리플렛은 본 사람을 셀 수 없습니다. 이 시스템은 본 사람·등록한 사람·전환된 사람을 다 셉니다."
