[프로젝트 155552 / 여행 플랫폼 위드 UX/UI 기획 및 화면 설계]
예산 500만원 / 30일 / 서울 강남 / 마감 06.04


안녕하세요, MaxImpact입니다.

위드 2.0 매칭 신규 기능 UX/UI 기획 의뢰글 잘 읽었습니다. 중개/매칭 플랫폼 기획은 단순 페이지 설계가 아니라, [매칭 알고리즘 시각화], [신뢰 시그널 노출 동선], [컨버전 깔때기 설계]가 핵심이라고 생각합니다. 기능정의서 분석부터 화면설계서 완성까지 책임지고 풀어내겠습니다.


[1. 제안 견적과 일정]

요청하신 5,000,000원 / 30일 그대로 수용합니다. 30일 일정은 다음과 같이 제안 드립니다.

- W1: 기능정의서 + 위드 1.0 분석, 경쟁사(트래블메이트, 트리플 동행 등) 벤치마킹, IA 재정비
- W2: 와이어프레임 (저충실도) + 사용자 플로우 다이어그램, 매칭 알고리즘 화면 시각화
- W3: 고충실도 화면설계서 작성, 핵심 인터랙션 명세
- W4: 검수/피드백 반영, Figma 디자인 시스템 정리, 산출물 최종 인계


[2. 산출물]

- Figma 화면설계서 (전체 페이지, PC + 모바일)
- 사용자 플로우 다이어그램 (회원가입, 매칭, 결제 등 핵심 시나리오)
- 컴포넌트 라이브러리 (Atomic Design 기반)
- IA 문서, 인터랙션 명세서 (PDF)


[3. 매칭 플랫폼 기획 차별점]

- 매칭 신뢰도 시각화 (프로필 인증 뱃지, 후기 점수, 매칭 성공률 등)
- 첫 메시지 진입 장벽 낮추기 (템플릿, 아이스브레이커 질문)
- 노쇼/이탈 방지 UX (사전 결제, 약속 알림, 평점 시스템)
- 매칭 매개 변수 시각화 (선호 지역, 여행 스타일, 예산 등)
- 매칭 후 채팅/일정 관리 동선


[4. 진행 방식]

서울 강남이시면 사전 미팅 직접 방문 가능합니다. 작업 진행 중 주 2회 Figma 진척 공유 + 1회 화면 검수 미팅 제안 드립니다. 의사결정이 빨라야 30일에 맞출 수 있어서 검수 응답 24시간 내 가능하신지 미팅에서 확인하면 좋겠습니다.


[5. 사전 검증 답변 준비]

위시켓 사전 검증 질문에는 별도로 답변 드릴 예정입니다. 추가로 궁금하신 부분 있으시면 메시지로 답변 가능합니다.


매칭 플랫폼 화면 설계 레퍼런스와 작업 샘플은 사전 미팅에서 공유 드릴 수 있습니다. 편하신 시간 알려주세요.
