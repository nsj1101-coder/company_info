[1. 제안 견적과 일정]

요청하신 25,000,000원 / 90일 조건 그대로 수용합니다. 사전 미팅에서 우선순위 정리 후 단계 배포 방식으로 진행해, 60일 시점에 1차 베타(수강생-강사 매칭 + 화상 통화)를 먼저 오픈하고, 90일까지 결제/관리자/랜딩 마무리하는 일정 제안 드립니다.


[2. 기술 구성안]

- 프론트엔드: Next.js 14 + TypeScript + Tailwind (PC/모바일 반응형)
- 백엔드: NestJS or Laravel 11 (운영 인력 환경에 맞춰 선택)
- 실시간 영상: Agora SDK 또는 LiveKit (한국 리전 지원, 안정성 검증된 옵션)
- 영상 녹화 보관: AWS S3 + 사인드 URL (수업 다시보기)
- 결제: 토스페이먼츠 + 정기결제(빌링) 옵션
- DB: PostgreSQL or MySQL 8


[3. 화상영어 플랫폼 핵심 설계]

- 강사별 가능 시간 캘린더 등록 -> 수강생이 시간 선택 -> 자동 매칭 확정
- 수업 10분 전 자동 입장 링크 발송 (이메일 + 카카오 알림톡)
- 1:1 룸은 1회용 토큰으로 보안 처리 (외부 침입 차단)
- 수업 종료 후 출석/평가 자동 기록
- 강사 정산은 월말 자동 집계 (수강료에서 수수료 차감 후 강사 계좌 입금)

부산 클라이언트시라 사전 미팅은 직접 방문 또는 화상 미팅 모두 가능합니다. 개발 진행은 주 1회 진척 공유 + 데모 링크 제공, 매 마일스톤마다 검수 후 다음 단계로 진입합니다.
