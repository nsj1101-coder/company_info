[1. 제안 견적과 일정]

요청하신 15,000,000원 / 60일 그대로 수용합니다. 60일 안에 양 플랫폼 출시까지 책임집니다.

- W1-W2: 기획/디자인 인수, GraphQL 스키마 분석, 어드민 API 연동 명세 정리
- W2-W6: 핵심 화면 개발 (홈, 카테고리, 상품 상세, 장바구니, 마이페이지)
- W4-W7: Stripe 결제 통합 (Stripe Connect 멀티벤더 옵션 검토)
- W6-W8: 입점몰 기능, 푸시 알림(FCM), 다국어 i18n
- W8: 통합 QA, 양 스토어 심사 제출 (iOS 평균 1-3일, Android 2-24h)


[2. 기술 구성안]

- 앱: React Native 0.76 + TypeScript (하나의 코드베이스로 양 플랫폼 동시 빌드)
- GraphQL 통신: Apollo Client + Codegen (스키마 변경 자동 반영)
- 상태관리: Zustand or React Query (서버 상태 + 클라이언트 상태 분리)
- 결제: Stripe React Native SDK (PaymentSheet, ApplePay/GooglePay 자동 포함)
- 푸시: Firebase Cloud Messaging
- 배포: Fastlane (자동 빌드 + 양 스토어 자동 업로드)


[3. 어드민 연동 안정성]

기존 어드민이 NestJS + GraphQL 구조라면 별도 모바일용 API 신설 없이 기존 스키마를 그대로 사용 가능합니다. 다만 모바일 화면에 최적화된 Query Fragment를 새로 정리해서 over-fetching을 줄이는 것이 좋습니다 (앱 응답 속도와 데이터 사용량 동시 개선).

기존 웹과 동일한 인증/세션 구조를 모바일에서도 유지 (JWT + Refresh Token 권장).

- 옵션 B: 핵심 마일스톤 시점만 상주 (기획 인수, 결제 통합, QA, 출시)
