4. 주요 마일스톤
고객사 확인이 반드시 필요한 4개 시점
Milestone 1 · Week 3 종료
디자인 시안 확정
전체 페이지 디자인 시안 + 디자인 시스템 확정. 이후 변경은 추가 일정 협의.
Milestone 2 · Week 4 종료
알파 빌드 시연
결제 → 다운로드 전체 플로우 1차 시연. 핵심 기능 동작 확인.
Milestone 3 · Week 6 종료
베타 빌드 시연
전체 기능 완성 + 관리자 페이지 검수. UAT(고객 인수 테스트) 시작.
Milestone 4 · Week 8 종료
운영 오픈 / 인수인계
운영 환경 배포, 도메인 전환, 매뉴얼 교육, 안정화 모니터링.
5. 주요 리스크 및 대응 방안
2개월 일정 내 발생 가능한 리스크와 사전 대응 계획
기존 XPay 결제 연동 정보 누락
기존 결제 모듈(XPay) 가맹점 키·연동 스펙·콜백 URL 등 자료 미수령 시 테스트 진행 불가
Week 1에 고객사로부터 XPay 연동 자료 및 테스트 계정 수령, 그동안 mock 결제로 개발 병행
디자인 시안 협의 장기화
시안 컨펌이 늦어지면 FE 개발이 막힘
Week 1~2 집중 협의, 시안 컨펌 후 변경은 추가 일정 협의 명문화
기존 DB 구조 호환성 문제
ASP/MSSQL → MySQL 마이그레이션 시 인코딩·비밀번호 해싱 불일치 가능
Week 1에 기존 DB 샘플 분석 선행, 회원 비밀번호는 첫 로그인 시 재설정 안내
콘텐츠(상품 정보) 입력 지연
기존 2,000건 이상 상품 데이터 이관 누락/지연
마이그레이션 스크립트로 일괄 이전 + 누락된 미리보기·미리듣기는 사후 보완
옵션 기능 일정 압박
해외결제·다국어·자동입금 등 옵션 7개 모두 포함 시 일정 초과 가능
옵션 기능은 우선순위 협의 후 단계 적용. 미포함 항목은 2차 개발로 분리
