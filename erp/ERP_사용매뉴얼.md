# 라린느 통합 ERP — 사용 매뉴얼

> 보면서 그대로 따라 하실 수 있게 만든 안내서입니다.
> 접속 주소: **https://maximpact.co.kr/lalune-erp**

---

## 0. 한눈에 보기

라린느 ERP는 **Cafe24·스마트스토어·자사몰 3곳에 흩어진 주문**을 한 곳에 모아
주문·재고·생산·발주·반품·고객·정산을 통합 관리하는 시스템입니다.

```
쇼핑몰에서 주문 엑셀 다운로드
        │  ① 양식대로 업로드
        ▼
   통합 주문(자동 정리) ──▶ 출고·생산·발주·반품 처리
        │
        └──▶ 재고 자동 계산 · 고객 자동 등록 · 매출/분석 자동 집계
```

---

## 1. 로그인 (제일 먼저)

1. 브라우저에서 **https://maximpact.co.kr/lalune-erp** 접속
2. 아이디 `admin` / 비밀번호 `admin1234` 입력 → **[로그인]**
3. 로그인되면 **대시보드**가 뜹니다.
4. 끝낼 때는 우측 상단 **[로그아웃]**.

> 비번이 틀리면 "아이디 또는 비밀번호가 올바르지 않습니다" 안내가 뜹니다.

## 2. 화면 구성

- **왼쪽 세로 메뉴(사이드바)**: 모든 기능 이동. 현재 보고 있는 메뉴는 파란색으로 표시됩니다.
- **상단 바**: 현재 페이지 이름(왼쪽) · 로그인한 사람·권한(오른쪽) · 로그아웃 버튼.
- **가운데 본문**: 선택한 메뉴의 내용(표·카드·검색창).

## 3. ⭐ 가장 중요 — 엑셀로 주문 올리기 (따라 하기)

**메뉴: 왼쪽 → "채널 주문 수집"**

평소 쇼핑몰(카페24 등) 관리자에서 주문을 엑셀로 내려받으시죠?
그 파일을 여기 올리면 시스템이 자동으로 정리해 줍니다.

### STEP 1. 양식 받기 (처음 한 번)
1. 화면 상단의 **[⬇ 엑셀 양식 다운로드]** 클릭
2. `라린느_주문업로드_양식.xlsx` 파일이 내려받아집니다.
3. 열어보면 **컬럼(주문몰·주문번호·주문자명·결제자·상품명·옵션·수량·금액·연락처…)** 과
   **샘플 2줄**이 들어 있습니다. → 이 형식에 맞춰 채우면 됩니다.

> 실제로는 쇼핑몰에서 받은 엑셀이 이미 이 형식과 비슷합니다. 그대로 올려도 됩니다.

### STEP 2. 파일 준비
- 쇼핑몰에서 받은 주문 엑셀(또는 위 양식에 채운 파일)을 준비합니다.
- 비워도 되는 칸은 비워도 됩니다(채널·상태·고객코드는 **시스템이 자동 분류**).

### STEP 3. 업로드
1. **유형 선택** (드롭다운):
   - 온라인 주문 → **"온라인 3몰 (Cafe24·스마트스토어·자사몰)"**
   - 전화·방문·B2B 주문 → **"오프라인 주문서"**
2. **[파일 선택]** → 준비한 엑셀 선택
3. **[업로드 & 수집]** 클릭

### STEP 4. 결과 확인
업로드되면 바로:
- **"○건 수집 완료 · 신규 고객 ○명 자동등록"** 메시지
- 아래 **수집된 원천 주문** 표에 방금 올린 주문이 추가됨
- 처음 보는 결제자(고객)는 **고객 마스터에 자동 등록**됩니다(고객 관리에서 확인 가능)
- **업로드 이력** 표에 파일명·건수·일시가 기록됩니다

> ✅ 올린 주문은 "통합 주문" 메뉴에서 채널·상태별로 정리되어 보입니다.

## 4. 메뉴별 사용법

### 📊 대시보드
- 들어오면 보이는 첫 화면. **총 매출 / 총 주문 / SKU 수 / 고객 수 / 출고완료 / 재고부족·품절** 한눈에.
- **채널별 매출**(기타·온라인·B2B·개인·대리점), **주문 상태**(접수·생산중·자수대기·출고완료·반품) 막대그래프.
- **최근 주문**, **발주 필요 품목** 표. 각 표의 "전체 보기 →"로 상세 이동.

### 🧾 통합 주문
- 올라온 모든 주문을 **한 줄=한 상품**으로 봅니다.
- **검색창**: 주문번호·고객명·상품명·SKU로 검색 → **[검색]**
- **채널 칩 / 상태 칩**: 클릭하면 해당 조건만 필터링 (예: "온라인" + "출고완료")
  - 여러 조건은 함께 적용됩니다. "전체"를 누르면 해제.
- 아래쪽 **페이지 번호(1·2·3…)** 로 다음 장 이동 (필터는 유지됩니다).

### 🚚 출고 관리
- 위쪽 카드: 접수·생산중·자수대기·**출고완료** 건수.
- 아래 표: 아직 출고 안 된(접수·생산·자수) 주문 목록.

### 🏭 생산 관리
- 생산번호(PRD-)별 진행 현황. 주문/생산/불량/입고 수량, 공장(본공장·외주), **대표님 확인**, **지연 여부** 표시.
- 검색창으로 생산번호·SKU·공장 검색.

### 🛒 발주·구매
- **발주서** 목록(PO-, 공급사, 입고예정).
- **발주 필요 품목 (자동 감지)**: 재고가 안전재고보다 적은 SKU를 자동으로 모아 보여줍니다.

### 📦 재고 관리
- SKU별 **현재고 / 안전재고 / 부족수량 / 권장발주량 / 상태(정상·부족·품절)**.
- 현재고 = 초기재고 + 입고 − 출고 + 반품 으로 **자동 계산**(직접 안 적어도 됨).
- 검색창으로 SKU·제품명 검색.

### ↩ 반품 관리
- 반품번호(RTN-)별 내역(주문번호·SKU·수량·사유). 총 반품건/반품수량 요약.

### 👕 상품 / SKU
- 상품 마스터. SKU·상품명·카테고리·컬러·사이즈·**원가·온라인가·B2B가·안전재고**.
- 검색창으로 SKU·상품명·카테고리 검색.

### 👤 고객 관리
- 고객 목록 + **고객 등급 자동 산정**(VIP=누적 500만↑ / 우수=100만↑ / 일반 / 신규).
- 누적매출·주문수도 자동 계산. 검색창으로 코드·이름·유형 검색.
- 엑셀 업로드 시 신규 결제자는 여기에 **자동 추가**됩니다.

### 📈 정산·분석
- **채널별 매출 비중**, **월별 매출 추이**, **고객 등급 분포**, **SKU별 매출 TOP10**.
- ※ 원가·이익(손익)은 주문↔상품 SKU 매칭 후 산출됩니다(현재 데이터는 SKU 체계가 채널마다 달라 매칭률이 낮아, 매출 중심으로 표시 — SKU 표준화 시 자동 표기).

## 5. 공통 사용 팁

- **검색**: 검색창에 입력 후 **[검색]** 버튼(또는 Enter).
- **필터 해제**: 칩의 "전체"를 클릭.
- **페이지 이동**: 표 아래 숫자 클릭. 필터·검색은 그대로 유지됩니다.
- **목록이 길 때**: 한 화면 50건씩 보여주고 페이지로 넘깁니다.

## 7. 자주 묻는 것 (FAQ)

**Q. 엑셀을 올렸는데 칸이 비어 보여요.**
→ 쇼핑몰 양식과 컬럼 순서가 다를 수 있습니다. **[엑셀 양식 다운로드]** 받은 형식에 맞춰 주세요.

**Q. 같은 파일을 두 번 올리면요?**
→ 그만큼 또 쌓입니다(중복). 한 번만 올려 주세요.

**Q. 재고 숫자를 직접 고치고 싶어요.**
→ 현재고는 입·출고로 자동 계산됩니다. (수기 조정 기능은 2차 확장에서 추가 가능)

**Q. Cafe24와 실시간 자동 연동은 안 되나요?**
→ 지금은 **엑셀 업로드** 방식입니다. **API 자동 수집**은 2차 과제로, 쇼핑몰 인증키를 받으면 5~10분 주기 자동 수집으로 업그레이드됩니다.
