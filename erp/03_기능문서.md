# 라린느 통합 ERP — 기능 명세서

> 엑셀 ERP(v45) 분석 기반. 각 기능의 입력/자동/연동을 엑셀 수식 동작 그대로 웹 로직으로 정의.
> 범례: **[입력]** 사용자 입력 · **[자동]** 시스템 계산 · **[연동]** 외부/타모듈 연계

---

## 0. 시스템 공통

- **번호 자동채번**: 주문 `ORD-YYYY-NNN`, 생산 `PRD-`, 반품 `RTN-`, 발주 `PO-`, 고객 `A##`, SKU 규칙.
- **권한**: 부서 기반 메뉴/필드 권한 (원가·손익·채널가격 마스킹).
- **공통 UX**: 목록 그리드(인라인 편집·일괄처리·CSV in/out), 검색·필터, 상태 뱃지, 감사로그(누가 언제 변경).
- **데이터 무결성**: 재고·매출 등 집계값은 **저장 안 하고 트랜잭션 로그에서 계산**(엑셀 수식 철학 계승, 단 DB 인덱스로 빠르게).

---

## 1. 채널 주문 수집 (★ 핵심 차별점 — 엑셀의 수동 복붙을 자동화)

엑셀 현재: 3개 몰 어드민에서 export → 카페_26/주문서_26에 **수동 붙여넣기**.

| 기능 | 설명 |
|------|------|
| Cafe24 자동수집 **[연동]** | Admin API로 주문 주기수집(5~10분). 신규 주문 자동 적재. |
| 스마트스토어 자동수집 **[연동]** | 커머스API(셀러). |
| 자사몰 수집 **[연동]** | 자사몰 형태에 따라 API/DB 직접. |
| 수동 등록 **[입력]** | 전화·방문·B2B 주문서(주문서_26 대체) 직접 입력. |
| 원본 보존 **[자동]** | 수집 원본(raw)을 보관 후 정규화(추적·재처리 가능). |
| 채널분류·주문상태 판정 **[자동]** | 카페_26 U~AB 수식 대체: 주문월/채널/상태/생산·자수·반품 플래그/고객매칭. |
| 결제자→고객 자동등록 **[자동]** | 신규 결제자명 → 고객마스터 자동 생성(중복제외, 코드부여). |

> 미팅 포인트: **"3개 어드민을 하나로 자동 통합"** = 그들의 1순위 고통 해결.

## 2. 통합 주문관리 (엑셀: 주문관리)

| 기능 | 구분 |
|------|------|
| 주문 목록/검색 (채널·상태·기간·고객·SKU) | [입력]/조회 |
| 주문 라인아이템(주문번호·고객·SKU·수량·단가) | [입력] |
| 고객명·유형·채널 자동 채움 (VLOOKUP 고객관리) | [자동] |
| 제품명·단가 자동 채움 (VLOOKUP 제품SKU, 채널별가격 적용) | [자동] |
| 총금액=수량×단가, 순판매수량=수량−반품수량 | [자동] |
| 주문상태 자동판정 (접수/생산중/자수대기/출고완료/반품) | [자동][연동] |
| 출고 처리 → 재고 차감 + (Cafe24건) 배송상태 회신 | [연동] |
| 일괄 상태변경·송장입력·CSV | [입력] |

---

## 3. 출고관리 (엑셀: 출고리스트·이번주출고·해외배송)

- 출고 대기/완료 현황, 물류 표기 **[입력]**
- 송장번호 입력 → Cafe24 주문 **배송상태 자동 회신** **[연동]** (Cafe24 유입 건만)
- 해외배송 별도 관리(통화·관세 비고)
- 출고확정 시 **재고 자동 차감** **[자동]**

---

## 4. 생산관리 (엑셀: 생산관리·자수·제작중)

| 기능 | 구분 |
|------|------|
| 생산지시 생성(PRD-, SKU, 주문/생산수량, 연결주문번호) | [입력] |
| 제품명·컬러·사이즈 자동(제품SKU) | [자동] |
| 불량수량·입고수량, **대표님확인** 단계 | [입력] |
| 공장 구분(본공장/외주), 생산담당 | [입력] |
| 리드타임 계산·**지연여부 자동 플래그** | [자동] |
| 자수 작업 관리(자수대기/완료) | [입력] |
| 생산완료 → **재고 자동 입고** | [자동] |

---

## 5. 발주·구매관리 (엑셀: 발주관리)

| 기능 | 구분 |
|------|------|
| 발주서(PO-, SKU, 발주수량, 공급사, 입고예정) | [입력] |
| 원부자재/임가공/완사입 구분 | [입력] |
| 제품명·원가 자동(제품SKU) | [자동] |
| **발주 필요 품목 자동감지**(부족수량 기반) | [자동] |
| 공급사 마스터 | [입력] |
| 입고확인 → 재고 입고 반영 | [자동] |

---

## 6. 재고관리 (엑셀: 재고관리)

| 기능 | 구분 |
|------|------|
| SKU별 현재고 = 초기 + 입고 − 출고 + 반품 | [자동] |
| 입·출고 내역(트랜잭션 로그) | [자동][입력] |
| 안전재고 대비 **재고상태/부족수량/발주권장** | [자동] |
| 부족 알림(대시보드 + 알림) | [자동] |
| 킵(예약) 재고 관리 | [입력] |

> 원칙: 현재고는 **직접 수정 불가**, 입출고 로그로만 변동(엑셀과 동일).

---

## 7. 반품관리 (엑셀: 반품관리)

- 반품 등록(RTN-, 주문번호, SKU, 수량, 사유) **[입력]**
- 카페_26 "반품완료/취소" 자동 집계 **[연동]**
- 제품정보 자동(제품SKU) **[자동]**
- **SKU별 반품률** 자동 + 주문관리 순판매수량 반영 **[자동]**

## 11. 외부 연동 요약

| 대상 | 방향 | 내용 |
|------|------|------|
| **Cafe24** | 양방향 | 주문 수집(in) / 출고·배송상태 회신, 재고·가격(out) |
| **스마트스토어** | 양방향 | 주문 수집(in) / 발송처리·재고(out) |
| **자사몰** | 양방향 | 주문 수집 / 재고 동기화 |
| **더존(회계)** | 단방향(2차) | 매출전표·거래처 push (API 점검 후) |

> 채널 연동은 **각 플랫폼 정책·키 발급 확인 후 단계 적용**. 1차는 주문수집+재고동기화, 배송회신·더존은 2차.

---

## 부록. 엑셀 → 웹 우선순위 (3채널 통합 1차)

1. **채널 주문 자동수집** (Cafe24·스마트스토어·자사몰) ← 최우선 고통
2. **통합 주문 + 재고 자동연동**
3. 생산·발주·반품
4. 상품·고객 마스터 + 권한
5. 분석/손익 대시보드
6. 더존 등 회계 연동(2차)
