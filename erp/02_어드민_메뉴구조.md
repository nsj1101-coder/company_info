# 라린느 통합 ERP — 어드민 메뉴 구조

> 엑셀 24개 시트를 웹 ERP 메뉴로 재구성. 분산된 작업 시트(제작중·자수·출고예정 등)는 상태 필터로 통합.
> 설계 원칙: **마스터 → 주문 → 운영 → 분석** 흐름 + 부서별 권한.

## 메뉴 트리 (전체)

```
🏠 대시보드
   └─ 통합 현황 (재고/영업/고객/손익 KPI · 채널별 매출 · 발주필요 · 실시간 주문)

📥 주문관리                        [핵심]
   ├─ 통합 주문                    ← 주문관리 (3채널 정규화 원장)
   ├─ 채널 주문 수집               ← 카페_26 / 주문서_26 (API 자동수집 + 수동등록)
   │    ├─ Cafe24
   │    ├─ 스마트스토어
   │    └─ 자사몰
   ├─ 출고 관리                    ← 출고리스트 (출고대기/완료, 송장)
   └─ 해외배송                     ← 해외배송건

🏭 생산관리
   ├─ 생산 지시                    ← 생산관리 (PRD-, 공장/외주, 대표님확인)
   ├─ 자수 관리                    ← 자수-미출고건
   ├─ 제작중 현황                  ← 제작중
   └─ 지연/리드타임 모니터

🛒 발주·구매관리
   ├─ 발주서                       ← 발주관리 (PO-, 원부자재/임가공/완사입)
   ├─ 공급사 관리                  ← 발주관리.공급사
   └─ 발주 필요 품목 (자동감지)     ← 재고관리 부족수량 연동

📦 재고관리
   ├─ 현재고 현황                  ← 재고관리 (입고+초기−출고+반품)
   ├─ 입·출고 내역
   ├─ 안전재고 / 부족 알림
   └─ 킵(예약) 재고

↩ 반품관리                        ← 반품관리 (RTN-, 사유, SKU별 반품률)

👕 상품관리
   ├─ 상품 / SKU                  ← 제품SKU (상품마스터)
   ├─ 채널별 가격                  ← 제품SKU (온라인/B2B/대리점/USD/엔화)
   └─ 카테고리 / 옵션(컬러·사이즈)

👤 고객관리
   ├─ 고객 마스터                  ← 고객관리 (A##, 유형, 채널, 담당자)
   └─ 고객 분석 / 등급             ← 고객분석 (누적매출·VIP)

📊 정산 · 분석                     [읽기 전용]
   ├─ 매출 분석 (일/월/분기/연)     ← 매출상세분석·일별·월별·분기별·연간분석
   ├─ 채널별 매출
   ├─ 손익(P&L)                   ← 손익분석 (채널별 매출·원가·이익)
   └─ SKU별 마진

⚙ 시스템
   ├─ 사용자 / 부서 권한
   ├─ 채널 연동 설정 (Cafe24·스마트스토어·자사몰 API 키)
   ├─ 번호체계 (ORD/PRD/RTN/PO/SKU)
   └─ 기준정보 / 코드
```

## 메뉴 ↔ 엑셀 시트 매핑표

| 웹 메뉴 | 대응 엑셀 시트 |
|---------|----------------|
| 대시보드 | ERP대시보드 |
| 주문관리 > 통합 주문 | 주문관리 |
| 주문관리 > 채널 수집 | 카페_26, 주문서_26 |
| 주문관리 > 출고 | 출고리스트, 이번주 출고 예정 |
| 주문관리 > 해외배송 | 해외배송건 |
| 생산관리 | 생산관리, 자수-미출고건, 제작중 |
| 발주·구매 | 발주관리 |
| 재고관리 | 재고관리 |
| 반품관리 | 반품관리 |
| 상품관리 | 제품SKU, 리스트(hidden) |
| 고객관리 | 고객관리, 고객분석 |
| 정산·분석 | 매출상세분석, 손익분석, 일/월/분기/연간분석 |
| 시스템 | 운영가이드(번호체계) |

> 통합으로 사라지는 시트: **제작중·자수·해외·출고예정** → 주문/생산의 **상태·태그 필터**로 흡수. **리스트(hidden)** → 상품관리 내부 처리.

## 화면 레이아웃 가이드 (UX)

- **좌측 고정 사이드바**(위 트리) + 상단 기간/채널 필터.
- **목록형 그리드**(엑셀 사용자 친화) — 인라인 편집, 다중선택, 일괄상태변경, CSV 내보내기. 대량 작업은 PC 그리드, 현장 조회는 모바일 반응형.
- 상세는 **슬라이드 패널/모달**(목록 이탈 없이 편집).
- 상태 뱃지: 접수/생산중/자수대기/출고대기/출고완료/반품.
