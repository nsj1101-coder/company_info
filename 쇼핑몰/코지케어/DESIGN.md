# 코지워커 쇼핑몰 — 디자인 가이드 & 도메인 컨텍스트

> **프로젝트**: 코지워커 쇼핑몰 (주식회사 코지케어)
> **카테고리**: 노인 복지용구 이커머스 (B2C + B2B 사업자)
> **출력 포맷**: HTML 정적 페이지 (다중 AI 협업)

## 0. 다른 AI에게 — 먼저 읽을 것

이 프로젝트는 **일반 쇼핑몰이 아닙니다**. 두 가지가 보통 쇼핑몰과 다릅니다:

1. **복지용구 제도** — 노인장기요양보험 가입자는 정가의 **15%만 부담**하고 구매 (서류·인정번호 검증 필요)
2. **결제 분리** — 코지케어는 제조사라 본인이 결제 못 받음. 복지용구는 관계사 **(주)베스트시니어**로 결제 위임

이 두 가지 때문에 일반 쇼핑몰에 없는 **"복지용구 구매" 분기·서류 제출·공단 확인 흐름**이 핵심입니다.

## 1. 도메인 핵심 용어 (필수 이해)

| 용어 | 의미 |
|---|---|
| **장기요양 인정번호** | 국민건강보험공단이 발급하는 장기요양 등급 인정자 번호. 복지용구 구매 시 필수 제출 |
| **복지용구** | 노인장기요양보험 적용 의료기기 (보행기·이동변기·목욕의자 등). 등록 사업소만 판매 가능 |
| **15% 부담금** | 복지용구 구매 시 본인 부담금 (나머지 85%는 공단이 지원) |
| **비급여** | 복지용구 제도 미적용 → 일반 정가 구매 |
| **복지용구사업소** | 공단 등록된 사업소. 일반 사업자는 판매 불가 |
| **수급자 / 보호자** | 구매자가 노인 본인일 수도, 자녀(보호자)가 대신 살 수도 있음 |

## 2. 사용자 그룹 (3개 페르소나)

### A. 일반 소비자 (B2C)
- 노인 본인 또는 보호자(자녀)
- 60대 이상 비중 높음 → **큰 글자·고대비·단순한 동선 필수**
- 복지용구 인정자: 15% 부담금으로 구매 → 서류 제출
- 비인정자: 일반 정가로 구매

### B. 사업자 회원 (B2B)
- 4가지 유형:
  - **복지용구사업소** — 직접 복지용구 판매
  - **인터넷 사업소** — 온라인 판매 채널
  - **재가복지센터** — 방문 요양/돌봄 기관
  - **기타 관련업체** — 도매·유통 등
- 사업자등록증 첨부 → 코지케어 승인 → 사용
- 혜택: **공급가**(도매가) 노출 + **포인트 적립**

### C. 어드민 (코지케어 운영자)
- 상품·주문·회원·서류·송장 관리
- 복지용구 서류 검토 (공단 확인 결과 입력)
- 사업자 가입 승인

## 3. 두 가지 구매 흐름 (이게 이 프로젝트의 본체)

### 🔵 흐름 1 — 복지용구 구매 (인정자)

```
상품 상세
  ↓ "복지용구" 버튼 클릭
복지용구 구매 페이지
  ↓ 인정번호 + 서류 입력/업로드
서류 제출 (1단계 → 2단계)
  ↓
사용자/구매자(보호자) 정보 입력
  ↓
(주)베스트시니어로 결제 위임 안내 표시
  ↓ "결제" 버튼
결제 (15% 부담금만)
  ↓
결제 완료
  ↓ 어드민이 공단 확인
  ├─ 정상: 출고 진행
  └─ 불가: 환불 + 안내
  ↓
송장 입력 → 문자 발송
```

### 🟢 흐름 2 — 일반 구매 (누구나)

```
상품 상세
  ↓ "일반구매" 버튼
장바구니 → 결제 (정가 100%)
  ↓
결제 완료 → 출고 → 송장 → 문자
```

### 🟠 흐름 3 — 사업자 구매

```
사업자 로그인
  ↓
상품 목록 (공급가·포인트 노출)
  ↓
사업자 전용 상세
  ↓
장바구니 → 결제
  ↓
포인트 적립 → 거래 내역
```

## 10. 협업 지침

다른 AI(디자인 AI)들에게 작업 분담 시:

1. **이 DESIGN.md를 먼저 공유** — 도메인 이해 없이 만들면 일반 쇼핑몰처럼 나옴
2. **PAGES.md의 페이지별 스펙** 보고 작업
3. 컬러·폰트·버튼 크기는 위 디자인 시스템 그대로
4. 상품 상세의 3가지 가격 박스 분기는 **반드시 같은 구조** 사용 (협업 일관성)
5. 작업 완료 후 `html/` 하위에 파일 저장, 파일명은 위 9.1 구조 따름
