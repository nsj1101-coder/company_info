## 📌 추후 적용 순서 (필요 시)

1. **로고/브랜드 텍스트** — `MediW` → `코지케어`, `M` → `C`
2. **사이드바 메뉴 항목** — 위 매핑 표대로 텍스트·svg 아이콘·href 변경
3. **대시보드 KPI** — 4개 카드 텍스트 교체
4. **차트** — 단일 막대 → 스택 막대 (복지/일반)
5. **활동 피드** — 데이터 배열 교체
6. **분포** — 회원 유형 → 매출 유형, 국가별 → 카테고리별
7. **컬러 토큰** — 블루 → 그린 일괄 치환
8. **개별 admin 페이지** — 각각의 도메인 변환 (회원/주문/상품/사업자 등)

지금은 RS_dv 원본 그대로. 미팅 시연 후 클라이언트 피드백 받고 변환 결정.
