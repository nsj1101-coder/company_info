## ⚡ 30초 요약 — 이 프로젝트 핵심

1. **노인 복지용구 쇼핑몰** — 일반 쇼핑몰 아님
2. **장기요양 인정자**는 정가의 **15%만 부담**해서 구매 (서류 검증 필요)
3. **결제 분리** — 코지케어는 제조사라 본인이 결제 못 받음 → 관계사 **㈜베스트시니어** 위임
4. **3가지 회원**: 일반 / 사업자(4종) / 어드민
5. **사업자 가입**은 사업자등록증 첨부 → 코지케어 승인 필요
6. **사업자 가격**: 공급가(도매) + 적립 포인트 별도 표시
