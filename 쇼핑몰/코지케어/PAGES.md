# 📄 페이지별 상세 스펙

각 페이지는 다른 AI에게 위임할 때 그대로 복사해서 줄 수 있도록 구성.

## 1. `index.html` — 메인 ⭐⭐⭐

**목적**: 첫 방문자 → 복지용구/일반 구매 양쪽 동선 노출 + 사업자 진입점 제공

### 섹션 구성 (위→아래)

1. **상단 알림 배너** — "복지용구 15% 부담금 안내 |  [사업자 로그인]" (에녹메이 참고)
2. **헤더** — 로고 / ☰메뉴 / 🛒장바구니 / 🔍검색
3. **카테고리 빠른 진입** — `BEST 50` `#SALE` `#신상` `#당일출고` 칩
4. **메인 히어로 슬라이드** — 코지워커 모델 사진 + "어르신을 위한 기업 / 본사 직영 안심 구매"
5. **NOW BEST COLLECTION** — 인기 4~8개 상품 그리드 (가격·복지용구 뱃지 표시)
6. **카테고리 그리드** — 보행기 / 휠체어 / 이동변기 / 목욕의자 / 기타
7. **복지용구 안내 박스** — "장기요양 인정자라면 15% 부담금" + [안내 보기 →]
8. **사업자 회원 안내** — "사업소·재가복지센터라면" + [사업자 가입 →]
9. **신뢰 배지** — 코지케어/베스트시니어 인증, 건강보험공단 관련
10. **푸터** — 회사 정보 / 약관 / 개인정보 / 사업자번호 / 대표 / 주소 / 전화

### 핵심 컴포넌트
- 상품 카드 (이미지·이름·가격·복지용구 뱃지·하트)
- 복지용구 뱃지 (왼쪽 상단) / 신상 뱃지
- 시니어 친화 큰 글씨 (16px 이상)

### 연결
→ `/shop/list.html`, `/shop/detail.html`, `/info/welfare-guide.html`, `/auth/biz-signup.html`

## 2. `shop/list.html` — 상품 목록 ⭐⭐⭐

**목적**: 카테고리/검색 결과 표시 + 필터링

### 섹션
1. 헤더 (메인과 동일)
2. **브레드크럼** — 홈 > 카테고리 > 보행기
3. **카테고리 사이드바** (PC) / 드롭다운 (모바일)
4. **필터 칩** — 복지용구만 / 당일출고 / 가격대 / 색상
5. **정렬** — 인기순 / 신상순 / 낮은가격 / 높은가격
6. **상품 그리드** — 2열(모바일) / 3~4열(PC)
7. **페이지네이션** 또는 무한스크롤

### 상품 카드 구성
```
┌─────────────┐
│ [복지용구]   │ ← 뱃지
│   사진       │
│             │
├─────────────┤
│ 코지워커 P02 │
│ ★ 4.5 (12)  │
│ 부담금 38,000│ ← 복지용구일 때 빨강
│ 정가 249,000 │
└─────────────┘
```

### 연결
→ `/shop/detail.html`

## 3. `shop/detail.html` — 상품 상세 ⭐⭐⭐ (이 프로젝트의 핵심)

**목적**: 단일 제품 페이지 — 3가지 분기 가격 박스 + 색상 선택 + 영상

### 섹션
1. 헤더
2. **이미지 갤러리** — 메인 이미지 + 썸네일 4개, 색상 변경 시 자동 롤링(30초 단위)
3. **공유/영상 버튼** — 우측 상단 ♡, ↗(공유), ▶(영상보기)
4. **제품명 + 별점**
5. **색상 선택 칩** — ● ● ● (최대 3개, 클릭 시 해당 색상 사진)
6. **가격 박스 (3가지 분기 자동 표시)** ← 핵심

#### 분기 A — 복지용구 등록 + 일반 둘 다 가능
```html
<div class="price-box welfare-box">
  <div class="row">
    <span>복지용구 15% 부담금</span>
    <strong class="welfare-red">38,000원</strong>
    <button class="info-btn">안내</button>
  </div>
  <div class="row">
    <span>비급여 일반 구매가</span>
    <strong>249,000원</strong>
  </div>
  <div class="cta-row">
    <span>구매하기</span>
    <button class="btn-welfare">복지용구</button>
    <button class="btn-normal">일반구매</button>
  </div>
</div>
```

#### 분기 B — 복지용구 비등록 (일반만)
```html
<div class="price-box normal-only">
  <p>복지용구 비 등록 제품</p>
  <div class="row">
    <span>일반 구매가</span>
    <strong>249,000원</strong>
    <button class="btn-normal">일반구매</button>
  </div>
</div>
```

#### 분기 C — 사업자 로그인 시
```html
<div class="price-box biz-box">
  <div class="row"><span>급여가/판매가</span><strong>249,000원</strong></div>
  <div class="row"><span>공급가</span><strong class="biz-navy">180,000원</strong></div>
  <div class="row"><span>적립포인트</span><strong class="biz-gold">5,000P</strong></div>
  <div class="row"><span>결제금액</span><strong>180,000원</strong></div>
  <div class="cta-row">
    수량 [▲ 1 ▼]
    <button class="btn-buy">구매</button>
  </div>
</div>
```

→ HTML에서는 3가지를 모두 표시하고 라벨로 구분 (실제 구현은 JS로 분기, 시안에서는 3개 다 보여줘서 디자인 확인)

7. **제품 상세 설명** — 디테일 페이지 (스크롤다운, 쿠팡 참고)
8. **리뷰 영역**
9. **하단 고정 CTA** (모바일) — 복지용구 / 일반구매 / 장바구니

### "안내" 팝업
- 복지용구 15% 설명 + 인정번호 안내 + 결제는 베스트시니어 진행 안내

### 연결
→ `/shop/checkout-welfare.html`, `/shop/checkout-normal.html`, `/info/welfare-guide.html`

## 4. `shop/cart.html` — 장바구니 ⭐⭐

**목적**: 담은 상품 관리 + 복지용구/일반 결제 동선 분기

### 연결

## 5. `shop/checkout-welfare.html` — 복지용구 결제 ⭐⭐⭐ (차별화 포인트)

**목적**: 인정번호 + 서류 제출 → 베스트시니어 결제

### 섹션 (스텝 4단계)

**스텝 1 — 구매자 정보**
- 구매자 이름 / 연락처 / 이메일 / 주소
- **사용자 / 보호자 구분** 라디오 (대신 사주는 경우 처리)
  - "사용자(본인)" — 이름·생년월일·인정번호
  - "보호자" — 보호자 정보 + 실제 사용자 정보 둘 다

**스텝 2 — 서류 제출 (핵심)**
- **장기요양 인정번호** 입력 (필수)
- **인정서/필요 서류** 업로드 (사진/PDF)
- 1단계: 인정서 첨부
- 2단계: 추가 서류 (있을 시)
- 안내 박스 — "서류 검토 후 공단 확인이 진행됩니다. 불가 시 환불 처리됩니다."

**스텝 3 — 배송지 + 옵션**
- 배송지 / 배송 메모 / 수령인

**스텝 4 — 결제 (베스트시니어 위임)**
- 결제 금액: 15% 부담금만
- **고지 박스**:
  > 주식회사 코지케어는 생산 업체로서 복지용구사업소가 아닌 관계로,
  > 복지용구는 관련 법규에 따라 당사 관계 복지용구사업소인
  > **㈜베스트시니어**로 결제가 이루어집니다.
- 결제 수단: 신용카드 / 계좌이체 / 카카오페이
- 약관 동의 체크
- [결제하기] (큼직한 CTA)

### 연결
→ `/shop/complete.html`

- **(복지용구 결제일 때만) 추가 안내 박스**:

  > 이 경우에는 별도로 연락드리고 환불 처리가 진행됩니다.
  >
  > 본 복지용구는 당사 관계사인 복지용구 사업소 **㈜베스트시니어**에서 진행 처리됩니다.
- 다음 단계 안내: 1) 서류 검토 → 2) 공단 확인 → 3) 출고 → 4) 송장 문자
- CTA: [주문 내역 보기] [쇼핑 계속]
