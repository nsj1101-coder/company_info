Solution 01

인력 · 스킬 · 표준화.

프로젝트를 처음부터 끝까지 경험해야 노하우가 생긴다 — 그 환경을 만들겠습니다.

01

표준 프로세스를
잡을 것입니다.

노션이든 스프레드시트든 — 프로젝트 A~Z를 한눈에 볼 수 있는 양식을 만들고, 모든 진행을 거기 태웁니다.

1.1

프로젝트 관리 양식 정립

노션/스프레드시트 — 어떤 도구든 형식을 정하고 모든 프로젝트를 거기서 관리.

1.2

디자인 컴포넌트 · 스타일 가이드

레퍼런스, 컴포넌트 라이브러리, 디자인 노하우 정리 — 업무 효율 자체를 올림.

1.3

천대표님 업무 스킬 가이드 OK

결과물이 좋으면 PM 입장에서 OK. 만족하고 있고 그대로 갑니다.

1.4

에이전시 · SI · SaaS 모두 다른 리딩 방식

경험이 적은 작업자도 힘들어함 → 공통 표준 + 프로젝트 유형별 가이드로 보완.

10 / 13
Solution 02

업무 우선순위는 PM이 정합니다.

불필요한 업무는 처음부터 차단 — 데드라인이 있는 일에 집중하기 위함입니다.

02

쓸데없는 업무는
진행하지 않습니다.

대표님 오더든 다른 PM 오더든 — PM 판단으로 우선순위 정리. 급한 건 당연히 유연하게 처리합니다.

2.1

결정권은 PM

모든 오더는 데드라인과 영향도 기준으로 PM이 우선순위를 조정합니다.

2.2

집중할 것에 집중

AI로 효율 올린 만큼, 매일 야근·매일 영업으로 회귀하면 의미 없음. 선택과 집중.

2.3

신입 3명 + 2개월 = 이만큼 했다

경험 적은 인원으로 지금까지 굴러온 것 자체가 성과 — 토대 위에 표준을 얹습니다.

2.4

2트랙 동시 가동

외부 = 돈 되는 것 우선, 내부 = "좋은 서비스 오픈" 목표. 분명히 분리.

2.5

현재 업무 포화 — 솔직한 현황 공유

주먹구구식으로는 더 못 끌고 갑니다. 성과 중심 PM 직무의 한계를 분명히 공유드립니다.

Solution 03

차주부터 워터폴. 6월 안에 소화합니다.

기존 프로젝트 + 외부 프로젝트 모두 중요. 차주 인력 합류 직후 내부 회의로 정리하겠습니다.

03

본격적으로
모든것을 핸들링 할 것입니다.

지금 해야 할 것, 앞으로 해야 할 것, 그것들을 하기 위한 준비 작업 — 세 가지를 분리해서 정리합니다.

3.1

차주 인력 합류 → 내부 회의

박주연 디자이너 합류 직후 전체 워크플로우 정리 미팅 진행.

3.2

워터폴 진행으로 전환

스프린트 × 워터폴 — 단계별 산출물 명확히, 의사결정 누락 방지.

3.3

업무 프로세스 6월 안 완성

지금 / 앞으로 / 준비 — 세 갈래로 정리해서 6월 내로 모든 업무가 흐름을 타게.
