3. 필수 기능 ↔ 기술 매핑
요청하신 11개 필수 기능을 각 기술로 어떻게 구현하는지 정리합니다.
#요구 기능구현 방식 / 기술유형
1결제 후 자동 다운로드기존 결제(XPay) 완료 콜백 수신 → 다운로드 토큰(JWT) 생성 → 인증된 다운로드 URL 발급 → 메일/페이지 자동 노출필수
2PDF/MP3/ZIP 업로드관리자 페이지 Multer 업로드 (대용량 청크 지원), MIME 검증, ZIP은 선택 업로드필수
3관리자 페이지React Admin (별도 빌드) + JWT Role-based Guard (admin/super-admin)필수
4관리자 상품 직접 등록4단계 카테고리·태그·가격·적립금·아이콘·미리보기파일·전체파일·MR 입력 폼 (기존 운영 UI 호환)필수
5구매내역 관리Orders + OrderItems + Downloads 테이블, 관리자 검색/필터/엑셀 export필수
6다운로드 제한(유효기간 자동 종료)downloads 테이블에 expires_at, max_count 컬럼 + 다운로드 시 검증 미들웨어 (예: 악보 1년/MR 1개월)필수
7악보 미리보기pdf-lib로 첫 1~2페이지 워터마크 삽입 후 별도 경로 저장 → 프론트는 PDF.js로 뷰어 렌더필수
8음원 미리듣기ffmpeg-static으로 30초 컷 자동 생성 + SoundCloud iframe 임베드도 병행 지원필수
9적립금RewardTransactions 테이블 (적립/사용/소멸), 주문 시 % 적립, 결제 시 사용 차감, 1년 유효기간필수
10검색어 태그tags + product_tags M:N 테이블, MySQL FULLTEXT 인덱스 + 자동완성 (Trie 또는 Elastic 옵션)필수
11비회원 구매guest_orders 별도 처리, 이메일+주문번호 인증으로 다운로드 페이지 접근옵션
12견적서 출력PDF 자동 생성 (pdfmake) + 다운로드 링크 메일 발송옵션
13필터링 강화(장르·악기편성)카테고리 4단계 + 다중 태그 + 악기편성 attribute 필터링옵션
14다국어(번역)react-i18next + 백엔드 상품설명 다국어 컬럼옵션
15게시판 정리공지·Q&A·후기 통합 board 도메인 + 첨부파일 업로드옵션
4. 보안 · 운영 · 마이그레이션
기존 사이트 Q&A에서 우려한 항목에 대한 대응 방안
