# AppSheet 실제 앱 — 10분 따라하기 (내 Google 시트로)

> 목표: 내가 만든 Google 시트로 **진짜 동작하는 모바일+데스크톱 앱**을 띄운다.
> 코드 0줄. 이게 라린느에 실제 납품할 물건의 축소판이다.

데이터 파일: 이 폴더의 `상품마스터.csv`, `주문.csv`

---

## STEP 1. Google 시트 만들기 (3분)

1. drive.google.com → **새로 만들기 → Google 스프레드시트**. 이름: `라린느-업무시스템`
2. 데이터 넣기 (둘 중 하나):
   - **(쉬움) 가져오기**: 파일 → 가져오기 → 업로드 → `상품마스터.csv` → "새 시트 삽입". 다시 `주문.csv`도 같은 방식.
   - **(직접)** 탭 2개(`상품마스터`,`주문`) 만들고 CSV 헤더/내용 붙여넣기.
3. 결과: 한 스프레드시트에 **`상품마스터` 탭 + `주문` 탭** 2개.
   - ※ 기본 'Sheet1' 탭은 삭제.

> 컬럼은 이미 AppSheet가 잘 인식하도록 설계됨:
> 상품마스터(SKU·브랜드·상품명·옵션·판매가·현재고·안전재고), 주문(주문번호·유입경로·거래처·SKU·수량·금액·상태·주문일)

## STEP 2. AppSheet 앱 자동 생성 (2분)

1. 그 시트에서 상단 **확장 프로그램 → AppSheet → 앱 만들기**.
2. AppSheet가 열리며 시트를 읽어 앱을 자동 생성(첫 실행 시 권한 허용).
3. 좌측 **Data**에 `상품마스터`,`주문` 두 테이블이 잡혔는지 확인.
   - 안 잡혔으면 Data → **+ Add Table** → 해당 탭 선택.

## STEP 3. 핵심 설정 3개만 (3분)

### ① 키(Key) 확인
- Data → `상품마스터` → **SKU**가 Key인지 확인. (아니면 SKU 행 Key 체크)
- `주문` → **주문번호**가 Key.

### ② 주문 → 상품 연결(Ref) — "어떤 상품 주문인지"
- Data → `주문` → `SKU` 컬럼 → **Type을 `Ref`**, ReferencedTableName = `상품마스터`.
- → 주문에서 상품을 드롭다운으로 고르게 되고, 상품 상세에서 관련 주문이 보임.

### ③ 상태를 드롭다운으로
- Data → `주문` → `상태` 컬럼 → Type `Enum` →
  Values: `신규주문 / 생산중 / 출고대기 / 출고완료`.

## STEP 4. 화면 다듬기 (선택, 2분)

- 좌측 **Views**:
  - `상품마스터` 뷰 → View type **deck/table**, 그룹을 `브랜드`로.
  - `주문` 뷰 → View type **table**, 그룹을 `상태`로 (칸반처럼 보임).
- 우측 상단 **모바일/태블릿/데스크톱** 토글로 반응형 확인.

## STEP 5. 진짜 동작 확인 ✅

- 우측 **미리보기 폰**에서 `주문` → **+** 새 주문 추가 → 저장.
- **Google 시트로 가보면 그 행이 진짜로 추가돼 있음** ← 이게 핵심(실데이터 양방향).
- 반대로 시트에서 값을 바꾸면 앱에도 반영(새로고침).

---

## (한 단계 더) 자동화: 출고확정 시 재고 자동차감

미팅에서 "자동화도 됩니다" 보여주려면:

1. 좌측 **Automation → + New Bot**.
2. Event: `주문` 테이블, **Updates only**, 조건 `[상태] = "출고완료"`.
3. Step: **Run a data action** → 새 Action 만들기:
   - Action: `상품마스터` 테이블, **Data: set the values of some columns**
   - `현재고` = `[현재고] - [관련주문수량]`
   - (간단버전: 주문의 SKU/수량을 참조해 해당 상품 현재고에서 차감)
4. 저장 후, 주문 상태를 '출고완료'로 바꾸면 → 상품 현재고가 자동으로 줄어듦.

> 이게 우리가 Apps Script로도 구현하는 "출고 → 재고 자동차감" 알고리즘.
> AppSheet Bot으로는 클릭만으로 구성됨.

---

## 미팅용 시연 시나리오 (2분)

1. 폰 미리보기에서 새 주문 추가 → **시트에 즉시 반영** 보여주기 ("실시간 클라우드 협업").
2. 주문 상태를 출고완료로 → **재고 자동차감** ("수기 입력/오류 제거").
3. 데스크톱/모바일 토글 → "현장은 폰, 사무실은 PC 동시 지원".
4. (있으면) Roles로 부서별 권한 → "부서별 메뉴 권한".

## 라린느에 실제 적용 시 추가되는 것
- 시트 탭: 거래처마스터 / 생산지시 / 입고 / 출고 / 정산
- Apps Script: Cafe24 주문 자동수집·재고 전송, 정산 PDF
- Looker Studio 대시보드
- Workspace 그룹 ↔ AppSheet Role 권한 매핑

> 참고: AppSheet는 **사용자 수만큼 라이선스 과금** → 라린느 현장 사용자 수 먼저 확인.
