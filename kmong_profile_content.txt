------------------------------------------------
[ B. 자기소개 본문 (상세) ]
[참고] 약 400자 / 강조 + 신뢰 + 차별점 + CTA 흐름
------------------------------------------------

안녕하세요, MaxImpact입니다.

기획부터 디자인, 프론트엔드, 백엔드, 배포, 운영까지 - 외주를 여러 곳에 쪼개지 않고 한 팀에서 처음부터 끝까지 책임지는 풀스택 웹 개발팀입니다.

[1] 무엇이 다른가
- 6년 이상 경력의 기획자, 디자이너, 개발자가 프로젝트마다 최적 조합으로 투입됩니다.
- 아이디어 수준의 요청도 화면설계서와 기능 명세로 구체화한 뒤 개발에 들어갑니다.
- 누락된 기획을 사전에 발견해 추가 비용 없이 보완합니다.

[2] 어떤 프로젝트가 가능한가
쇼핑몰, 구독 SaaS, 결제 시스템, 중계 매칭 플랫폼, 세무 회계 사이트, 예약 시스템, 관리자 어드민, 기업 소개 사이트 - 단순 랜딩부터 대규모 플랫폼까지 모두 대응합니다.

[3] 기술 스택
Next.js, React, TypeScript, Tailwind, PHP, MySQL, Prisma, AWS, OpenAI/Claude API 등 최신 안정 기술로 빠르고 견고하게 만듭니다.

[4] 사후 지원
납품 후 1개월 무상 A/S 기본 포함, 이후 월 정액 유지보수 협약 가능합니다.

먼저 무료 상담부터 편하게 메시지 주세요. 30분 이내에 답변드립니다.


------------------------------------------------
[ C. 서비스별 보강 카피 (3종) ]
[참고] 현재 등록된 서비스의 상세 설명에 추가 사용
------------------------------------------------

[C-1. 외주 개발팀 웹사이트/앱 신규 제작 - 30만원~]
중규모 이상의 웹사이트 또는 앱 신규 제작을 풀스택으로 진행합니다.
회원/결제/관리자/외부 API 연동까지 한 팀에서 처리합니다.

포함 영역
- 기획서 작성 및 화면설계서
- UI/UX 디자인 (Figma)
- 프론트엔드 개발 (Next.js, React)
- 백엔드 API 개발 (Node, PHP)
- DB 설계와 마이그레이션
- 결제 PG 연동 (토스, KCP, Stripe)
- 배포와 SSL, 도메인 연결
- 1개월 무상 A/S

진행 방식
- 무료 상담으로 범위 확인
- 견적서 발송 (1주 이내)
- 착수금 50% 결제 후 시작
- 중간 30%, 납품 후 20% 결제
- 카카오톡과 노션으로 진척 공유

이런 분께 추천
- 단순 템플릿이 아닌 맞춤형 웹이 필요한 분
- 기획이 완성되지 않아도 함께 다듬어 갈 분
- 출시 후 장기 운영 파트너가 필요한 분


[C-2. 홈페이지 사이트 제작 - 1만원]
소규모 랜딩 페이지부터 시작합니다. 1만원으로 견적 미팅을 진행하고, 실제 제작 비용은 페이지 수와 기능에 따라 별도 산정합니다.

가능한 작업
- 기업 소개 1~5페이지
- 제품 랜딩 페이지
- 이벤트 페이지
- 반응형 웹 디자인
- SEO 메타데이터 최적화

이 1만원 상담에 포함된 것
- 요구사항 정리 30분 미팅
- 페이지 수와 기능 협의
- 정식 견적서 발송
- 일정 산정

이런 분께 추천
- 일단 정확한 견적부터 받아보고 싶은 분
- 단순 소개 페이지가 빠르게 필요한 분
- 디자인은 트렌디하면서 가성비도 챙기고 싶은 분


[C-3. 프로젝트 성공률을 높이는 기획서 제작 - 1만원~]
개발에 들어가기 전, 기획부터 정리합니다. 기획서가 정리되어 있으면 개발 견적이 명확해지고 일정이 흔들리지 않습니다.

산출물
- 화면 설계서 (와이어프레임)
- 기능 명세서
- 사용자 시나리오
- DB 구조 초안
- 우선순위 정리 (1차/2차 배포 분리)
- 예상 견적 가이드

이 작업을 거치면
- 견적이 정확해집니다 (오버 비용 방지)
- 누락된 기능을 사전에 발견합니다
- 외주 업체와 같은 언어로 대화할 수 있습니다
- 개발 도중 추가 비용 발생을 줄입니다

이런 분께 추천
- 아이디어는 있는데 어디서 시작할지 모르는 분
- 견적을 정확히 받고 싶은 분
- 이전에 외주가 망한 경험이 있는 분

[ D. 포트폴리오 설명 (승인 통과 후 사용) ]
[참고] 포트폴리오 한 건당 약 200~300자 권장
------------------------------------------------

[D-1. 일반 풀스택 사례용 템플릿]
제목: 풀스택 웹 플랫폼 신규 구축

설명:
회원/상품/결제/관리자/외부 API 연동까지 풀스택 개발을 한 팀에서 진행한 사례입니다. 기획서 작성부터 와이어프레임, UI 디자인, 프론트엔드/백엔드 구현, AWS 배포까지 전 과정을 책임지고 완성했습니다.

사용 기술
- Next.js, React, TypeScript
- Node.js, PostgreSQL
- AWS EC2, S3, CloudFront
- 토스페이먼츠 PG 연동

진행 기간: 8주 / 결과: 정상 오픈, 1개월 무상 운영 지원 완료


[D-2. AI 기능 내장 SaaS 템플릿]
제목: AI 챗봇 내장형 SaaS 구축

설명:
OpenAI와 Claude API를 활용해 자동 응답, FAQ, 추천 기능을 SaaS 제품 핵심 기능으로 내장한 사례입니다. 단순 외부 위젯이 아닌, 제품 흐름 안에서 자연스럽게 작동하도록 설계했습니다.

사용 기술
- Next.js, React, Tailwind
- NestJS, Prisma, PostgreSQL
- OpenAI GPT-4o API, Claude 3.7 API
- Stripe 정기결제

차별점: 응답 캐싱과 토큰 사용량 최적화로 운영 비용 30% 절감


[D-3. 커머스 사례 템플릿]
제목: 종합 커머스 풀 커스텀

설명:
상품 등록, 결제, 배송, 리뷰, 쿠폰까지 완성형 쇼핑몰을 풀 커스텀으로 구축한 사례입니다. 카페24 임대형이 아닌, 자체 어드민에서 운영자가 직접 모든 데이터를 다룰 수 있는 구조입니다.

사용 기술
- Next.js, TypeScript
- PHP 8, MySQL 8
- KCP 결제, 팝빌 세금계산서
- AWS LightSail

특징: 수십만 SKU 대량 등록 모듈, 비동기 큐 워커 포함

[ E. 자주 묻는 질문 (FAQ) ]
[참고] 크몽 서비스 페이지의 FAQ 영역에 활용
------------------------------------------------

Q1. 견적은 어떻게 받나요?
크몽 메시지로 [원하는 서비스 + 참고 사이트 + 기능 목록] 보내주시면 1주 이내에 정식 견적서를 보내드립니다. 30분 이내 1차 회신 가능합니다.

Q2. 기획이 안 되어 있어도 시작할 수 있나요?
가능합니다. 아이디어 수준의 요청을 받아 화면설계서와 기능 명세로 정리해 드립니다. 별도 기획 서비스(1만원~)를 먼저 진행해도 좋고, 본 개발 견적 안에 포함해 진행해도 됩니다.

Q3. 결제 구조는 어떻게 되나요?
착수금 50% 결제 후 작업 시작, 중간 검수 시점에 30%, 납품 완료 후 20%로 진행됩니다.

Q4. 납기 보장은 어떻게 하나요?
지금까지 50건 이상의 완료 프로젝트에서 100% 납기 준수 기록을 유지하고 있습니다. 일정 산정 시 버퍼를 포함해 견적하므로 안전합니다.

Q5. 납품 후 문제가 생기면?
1개월 무상 A/S가 기본 포함됩니다. 버그 수정, 사소한 운영 지원 모두 포함입니다. 이후 장기 운영은 월 30만원~의 정액 유지보수로 협의 가능합니다.

Q6. 어떤 기술을 사용하나요?
Next.js, React, TypeScript, Tailwind, PHP, MySQL, PostgreSQL, Prisma, AWS, Vercel, OpenAI/Claude API 등 최신 안정 기술을 사용합니다. 발주처 기존 시스템과의 호환성을 우선합니다.
