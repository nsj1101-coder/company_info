권장 사양 (출시 시점)

애플리케이션 서버

vCPU 2 RAM 4GB SSD 80GB

초기 DAU 500~1,500 수준 안정 운영 가능. DAU 5,000+ 시 vCPU 4·RAM 8GB로 1단계 업그레이드 권장.

DB 서버 (또는 Managed)

vCPU 2 RAM 4GB SSD 100GB

상품 인덱스·검색 캐시는 Redis가 흡수 → DB 부하 최소화. 매일 자동 백업 + 7일 보관 권장.

대량 등록 워커

vCPU 2 RAM 4GB Redis

웹 서버와 분리. 등록 시간이 길어도 사용자 사이트는 영향 없음. 야간 일괄 처리에 최적.

결정 기준 (How to Choose)
  • PHP 선택 · 발주처 내부에 PHP 개발자가 있거나, 운영 인력 채용 풀을 우선시할 때
  • Next.js 선택 · 향후 모바일 앱(React Native) 확장 계획이 있거나, UX 응답성을 최우선할 때
  • 하이브리드 · 사용자 사이트는 Next.js, 어드민은 Laravel Filament (별도 견적 필요)
권고 옵션 A · PHP 8.3 + Laravel 11 기본 채택 — 국내 의료기기 B2B 도메인에서 PG·세금계산서·호스팅 운영 안정성이 가장 검증되어 있고, 발주서 명시 스택과 일치하여 인계·유지보수가 수월합니다.
