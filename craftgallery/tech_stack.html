데이터 흐름과 AI 캐시 구조.

고객이 색상을 클릭하면 캐시 먼저 확인, 없으면 Gemini 호출, 결과는 영구 저장. 같은 작품과 같은 색상 조합은 한 번만 생성되고 이후 모든 고객에게 즉시 반환됩니다.

LAYER 01 · CLIENT

고객 — 갤러리 메인 · 작품 상세 · 결제

베이지 샌드톤 미니멀 디자인. 모바일 우선 반응형. PWA 캐시로 재방문 속도 최적.

Next.js 16React 19Tailwind 4PWA
LAYER 02 · ADMIN

본사·작가 어드민 — 같은 코드, 다른 권한

본사 로그인은 작가 승인·작품 검수·전체 정산. 작가 로그인은 자기 작품·자기 주문만. NextAuth 역할 기반 라우팅.

NextAuth 5역할 미들웨어인라인 편집기
LAYER 03 · API

Next.js Route Handlers — 풀스택 통합

웹과 어드민이 같은 API를 사용. 작품 조회, AI 색상 요청, 결제, 주문, 정산 모두 단일 API. 권한 미들웨어로 자동 검증.

Route HandlersTypeScriptZod 검증Prisma Client
LAYER 04 · AI

Gemini API + 캐시 — 한 번 생성, 영원 재사용

색상 선택 → DB에서 캐시 키 (작품 ID + 색상 ID) 조회 → 있으면 즉시 반환, 없으면 Gemini 호출 + 결과 S3 저장 + DB 매핑. 평균 캐시 적중률 90%+ 예상.

Gemini 2.5 Flash ImageS3 캐시마스크 좌표 저장

PostgreSQL — 작가·작품·주문·정산

작가, 작품, 색상 옵션, 마스크 좌표, 캐시 매핑, 주문, 결제 결과까지 한 DB. 정산은 월 단위 집계 뷰로 빠르게 산출.

결제 PG
토스페이먼츠 결제창 v2 (국내 단일) — 카드·간편결제·계좌이체 한 번에. 비회원 결제 지원.
해외 결제 (Stripe·PayPal) — 1차에서 제외. 2차 단위에서 협의.
배송 처리
수동 출고 (어드민에서 운송장 번호 직접 입력) — 1차 단위에서 자동화 제외. 작가별 출고 직접 관리.
택배사 API 연동 — 2차 단위 별도 견적 (CJ대한통운 등).
호스팅
Vercel · 인천 리전 — Git push 자동 배포. 트래픽 자동 스케일. 모바일 첫 로드 1초 이내.
자체 운영 (AWS ECS) — 운영 부담 증가. 1차 단위 규모에서 부적합.
정산 모듈
월 단위 자동 집계 + 어드민에서 확정·통보 — PG 수수료 차감 후 작가별 금액 자동 산출.
실시간 정산 — 1차 단위에서 과도. 월 단위로 충분.
