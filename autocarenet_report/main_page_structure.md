## 2. 섹션별 상세 구성

### ① 상단 유틸바 (회원 인증)
- 입력: 사용자 이름(textbox), 비밀번호(password), Submit 버튼
- 링크: 회원가입(JoiningMembership.aspx), 페이스북 활동(facebookactivity.aspx), 비밀번호 찾기(ForgetPassword.aspx)

### ② 로고 헤더
- `images/logo.jpg` (326×77) → Default.aspx 링크

### ③ 글로벌 내비게이션 (GNB) — 2열, 총 20개 메뉴
**1열:** 홈 · 마이페이지 · 정비업체찾기(FindShop?id=1) · 중고자동차(FindShop?id=24) · 29 모범업체 프로샵(CertifiedListing) · 수입차 정비(ImportCarRepair) · 1급정비공장(FindShop?id=16) · 안전점검표(InspectionSheet) · 작업견적서(Estimate) · 캠핑그라운드(FindShop?id=43)
**2열:** 무료서비스 · 할인서비스 · 이벤트 · 전자쿠폰 · 상품권 · VIP 오토케어클럽(VIPMembershipListHome) · 보너스포인트 · 리뷰 사용후기 · 내차팔기 · 모범업체 업그레이드 신청(SearchYourShop)

### ④ 좌측 — 서비스 카테고리 (DataList, 12개 아이콘 리스트)
자동차 서비스/정비 · 바디샵/정비공장 · 세차/디테일 · 자동차 유리 · 알람/스테레오 · 트랜스미션 · 타이어/얼라인먼트 · 검사 점검 테스트 · 머플러/배기장치 · 중고자동차 · 새 자동차 · 렌트 자동차
- 하단: 금호타이어 배너 링크

### ⑤ 우측 상단 — 메인 배너 슬라이더
- responsiveSlides 자동 롤링, 이미지 5장 (위 URL 참고)

### ⑥ 차량 정보 검색/가입 위젯
- 연식 드롭다운 (Select / 2026~1982)
- 제조사 드롭다운 (홀덴·혼다·현대 … 110개 브랜드, 한글+영문 혼재)
- 모델 드롭다운 (제조사 선택 시 AJAX 연동)
- [가입하기] 버튼

### ⑦ 혜택 피드 (4분할 카드)
- 무료 서비스(0) / 전자 쿠폰(0) / 이벤트(0) / 할인 서비스(0)
- 각 카드 "+ 자세한 내용은" 링크 (현재 데이터 0건)

### ⑧ 협력사 배너
