Approach

기능은 유지하고, 디자인과 데이터를 새로 짓습니다

6주에 맞추기 위해 백엔드 비즈니스 로직 전면 재작성은 범위에서 제외합니다. 대신 ① 핵심 사용자 화면의 반응형 디자인 리뉴얼과 ② 200개 테이블 데이터의 안전한 이행·검증, 두 트랙을 병렬로 진행합니다. 신규 프론트엔드에 얇은 API 레이어를 두어 기존 데이터와 로직을 그대로 재사용함으로써 위험과 공수를 최소화하는 구조입니다.

Risk & Control

핵심 리스크와 관리 방안

WebForms는 부분 전환이 불가능합니다. 핵심 화면을 신규 구축으로 처리하고 범위를 고정합니다.
비즈니스 로직이 저장프로시저에 흩어져 있을 수 있습니다. API 레이어로 재사용하되 의존도는 1주차 실사로 확정합니다.
200개 테이블 중 실가동 비율은 미확인 상태입니다. 본 계획은 활성 120개 이하를 가정하며 실사 후 일정을 조정합니다.
데이터 정합성이 일정보다 우선입니다. 검증을 통과하지 못하면 컷오버를 연기하고 롤백 플랜을 상비합니다.
Recommended

1주차 정밀 실사를 별도 단계로 진행하는 것을 권장합니다

스키마·소스·연동을 먼저 확인한 뒤 잔여 5주의 범위·일정·금액을 확정 계약(SOW)으로 체결하는 구조입니다. 고객은 검증된 근거로 신뢰를, 수행팀은 안전한 범위를 확보합니다. 막연한 추정 대신 실측으로 시작합니다.
