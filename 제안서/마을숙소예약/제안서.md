# 마을 통합 소개·숙박예약 플랫폼 구축 제안서

> 하나의 마을을 중심으로 마을 소개 · 콘텐츠 아카이브 · 다수 숙박업체 통합 예약을 한 사이트에서 제공하는 통합 플랫폼

---

## 1. 사업 개요

| 구분 | 내용 |
|------|------|
| 사업명 | 마을 통합 소개·숙박예약 플랫폼 구축 |
| 발주처 | 준공공기관 (클라이언트) |
| 사업 방식 | 컨소시엄 (개발·기획·디자인 + 촬영 전문업체) |
| 핵심 목표 | 마을 소개 홈페이지 + 다수 숙박업체 통합 예약 + 콘텐츠 아카이브를 하나의 사이트로 통합 |
| 참고 레퍼런스 | 전주한옥마을 / 고령몰 / 서울한옥 stay — 대비 **더 높은 디자인 퀄리티·인터랙티브 마을 지도** 지향 |

### 사업 추진 방향
- 단순 숙박 예약 사이트가 아닌 **"마을 그 자체를 담는 통합 포털"** 로 기획
- 마을 소개(역사·유물·이벤트) → 숙박/상점 소개 → 예약·결제까지 **끊김 없는 단일 동선** 구성
- 관리자가 직접 콘텐츠를 운영할 수 있는 **CMS 기반 구조** 로 구축하여 운영 지속성 확보

---

## 2. 고객 요청사항 반영 (4대 영역)

### ① 콘텐츠 기획 및 제작
- 아카이브 구조 설계 및 유물 자료 분류 체계 수립
- 신규 콘텐츠 페이지 기획 (마을 스토리·역사·문화)
- 마을 아키페스타(이벤트) 운영 페이지 기획
- 숙박 및 상점 콘텐츠 재정비 및 신규 제작

### ② 촬영 및 디자인 제작 *(촬영은 컨소시엄 전문업체 수행)*
- 전문 사진 및 드론 촬영 *(컨소시엄 진행, 예산 포함)*
- 홈페이지 메인·서브 디자인 리뉴얼 및 UI/UX 개선
- 반응형 웹 디자인 최적화 (PC·모바일·태블릿)
- 마을 지도 표기 개선 (인터랙티브 지도)

### ③ 시스템 개발 및 기능 개선
- 콘텐츠 아카이브 페이지 구축
- 관리자 페이지 통계 시스템 연동
- SNS 연동 기능 구축
- 팝업 및 공유 기능 개발
- 서버 세팅 및 안정화

### ④ 교육 및 운영 지원
- 관리자 교육 진행
- 운영 매뉴얼북 제작
- 사업 결과보고서 제작

## 3. 사용자(프론트) 페이지 정의

> 마을 소개부터 예약 완료까지 단일 동선. 아래 페이지 단위로 기획·디자인·개발 진행.

| No | 페이지명 | 정의 (한 줄 설명) |
|----|----------|------------------|
| F-01 | 메인 홈페이지 | 마을 대표 비주얼·핵심 콘텐츠·바로가기·이벤트·예약 진입을 모은 통합 첫 화면 |
| F-02 | 마을 소개 | 마을의 역사·유래·특징을 사진과 함께 소개하는 브랜드 페이지 |
| F-03 | 인터랙티브 마을 지도 | 숙소·상점·관광지를 지도 위에 표기하고 클릭 시 상세로 연결되는 지도 페이지 |
| F-04 | 콘텐츠/스토리 | 마을 문화·테마별 이야기를 담는 기획형 콘텐츠 페이지 |
| F-05 | 아키페스타(이벤트) 안내 | 마을 행사·축제·프로그램 일정과 내용을 안내하는 페이지 |
| F-06 | 아카이브 목록 | 유물·기록 자료를 분류 체계에 따라 모아 보여주는 아카이브 메인 |
| F-07 | 아카이브 상세 | 개별 유물·자료의 사진·설명·메타정보를 보여주는 상세 페이지 |
| F-08 | 숙박업체 목록 | 마을 내 다수 숙박업체를 한눈에 비교·탐색하는 리스트 페이지 |
| F-09 | 숙박업체 상세 | 개별 숙소의 소개·사진·객실·요금·예약 진입을 담은 상세 페이지 |
| F-10 | 객실/날짜 예약 | 날짜·인원·객실 선택 및 예약 가능 여부를 확인하는 예약 페이지 |
| F-11 | 예약 확인/결제 | 예약 정보 확인 및 결제(PG 연동)를 진행하는 페이지 |
| F-12 | 예약 완료/내역 | 예약 완료 안내 및 사용자의 예약 내역을 확인하는 페이지 |
| F-13 | 상점 소개 목록 | 마을 내 상점·먹거리·체험 업체를 모아 보여주는 리스트 페이지 |
| F-14 | 상점 상세 | 개별 상점의 소개·사진·위치·연락처를 담은 상세 페이지 |
| F-15 | 공지사항/소식 | 마을 공지·뉴스·보도자료를 게시하는 게시판 |
| F-16 | 갤러리 | 전문 촬영·드론 사진·영상을 모아 보여주는 미디어 페이지 |
| F-17 | 로그인/회원가입 | 회원 가입·로그인 및 소셜(SNS) 로그인 연동 페이지 |
| F-18 | 마이페이지 | 회원 정보·예약 내역·취소·문의를 관리하는 개인 페이지 |
| F-19 | 고객센터/FAQ | 자주 묻는 질문·이용 안내·문의 접수를 제공하는 페이지 |

**프론트 페이지 총 19종**

## 4. 관리자(CMS) 페이지 정의

> 관리자가 직접 콘텐츠·예약·통계를 운영하는 CMS 백오피스.

| No | 관리자 페이지명 | 정의 (한 줄 설명) |
|----|----------------|------------------|
| A-01 | 대시보드 | 방문·예약·매출 핵심 지표를 한눈에 보는 통계 메인 |
| A-02 | 통계/리포트 | 기간별 방문·예약·매출을 그래프·표로 분석하고 내보내는 페이지 |
| A-03 | 메인/배너 관리 | 메인 화면 비주얼·배너·노출 콘텐츠를 편집하는 페이지 |
| A-04 | 콘텐츠 관리(CMS) | 마을 소개·스토리·콘텐츠 페이지를 직접 등록·수정하는 페이지 |
| A-05 | 아카이브 관리 | 유물·자료를 분류 체계에 따라 등록·수정·정렬하는 페이지 |
| A-06 | 지도 관리 | 지도 위 숙소·상점·관광지 마커와 정보를 등록·편집하는 페이지 |
| A-07 | 이벤트(아키페스타) 관리 | 행사·축제·프로그램 일정과 내용을 등록·관리하는 페이지 |
| A-08 | 숙박업체 관리 | 숙박업체·객실·요금·재고를 등록·수정하는 페이지 |
| A-09 | 예약 관리 | 들어온 예약을 조회·승인·취소·환불 처리하는 페이지 |
| A-10 | 상점 관리 | 상점 정보·사진·노출을 등록·관리하는 페이지 |
| A-11 | 회원 관리 | 회원 정보 조회·등급·탈퇴를 관리하는 페이지 |
| A-12 | 게시판/공지 관리 | 공지사항·소식·FAQ 게시글을 작성·관리하는 페이지 |
| A-13 | 팝업 관리 | 메인 팝업·공지 팝업을 등록·노출 기간을 설정하는 페이지 |
| A-14 | SNS 연동 관리 | 인스타·페북 등 SNS 연동·공유 설정을 관리하는 페이지 |
| A-15 | 환경설정/권한 관리 | 사이트 기본 설정·관리자 계정·접근 권한을 관리하는 페이지 |

**관리자 페이지 총 15종**

## 5. 핵심 기능 요약

- **통합 예약 시스템** : 다수 숙박업체를 한 사이트에서 날짜·객실 단위로 예약·결제(PG 연동)
- **인터랙티브 마을 지도** : 레퍼런스 대비 차별화된 핵심 비주얼 요소
- **콘텐츠 아카이브** : 유물·자료 분류 체계 기반 디지털 아카이브
- **CMS 운영** : 관리자가 코드 수정 없이 콘텐츠·예약·통계 직접 운영
- **통계 대시보드** : 방문·예약·매출 데이터 시각화
- **SNS 연동·공유 / 팝업** : 마케팅·확산 기능
- **반응형 최적화** : PC·모바일·태블릿 완벽 대응

## 7. 기대 효과

- 분산된 숙박·상점·콘텐츠를 **하나의 마을 포털**로 통합하여 이용 편의성 극대화
- 관리자 CMS 기반으로 **사업 종료 후에도 자체 운영 지속 가능**
- 레퍼런스 대비 차별화된 디자인·인터랙티브 지도로 **마을 브랜드 가치 제고**
